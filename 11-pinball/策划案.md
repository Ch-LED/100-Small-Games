# 11-pinball — 策划案

## 定位

**三维弹球——复刻《3D Pinball for Windows – Space Cadet》的台面**。

玩家操控左右两个 flipper，把弹珠打向台面上的机关。三条球，掉光收场。

这是全库**第二款 3D 游戏**（继 `10-marble-race`），也是第一款**玩家角色不在场**的游戏——玩家不操控任何物体，只操控**两个挡板的动作**，球由重力与弹力支配。

**这一版是「复刻」而不是原创**：台面的每一段墙、每一个机关的位置，都取自原版游戏的资源文件（见下）。**只复刻台面与机关，不复制它的任务与军衔规则。**

## 参考（复刻的数据来源）

- **仓库**：<https://github.com/k4zmu2a/SpaceCadetPinball> —— 原版 `PINBALL.DAT` 的反编译重制（C++）。
  **本地副本：`E:/SpaceCadetPinball`，刻意放在 Godot 仓库之外**（放进去会被引擎当资源扫描，`git status` 也会被淹）。它是**只读参考**，不参与构建。
- **三份有用的东西都在里面**：
  - `Doc/.dat dump.txt` —— 原版资源的完整转储（541 个组）。**台面的全部几何都在这里**：墙、保险杠、靶、洞、坡道的坐标，一个不缺。
  - `Doc/.dat file format.txt` —— 该 dump 的格式说明（类型码、浮点属性的含义）。
  - `Screenshots/` —— 台面截图，用来核对布局方向。
- **原版坐标直接沿用，不做缩放**：台面 **x ∈ [−8, 8]、y ∈ [−14, 13.88]**（16 × 27.88），球半径 **0.3**。这和本作原有的台面尺度（14 × 28）几乎一样，所以**原版的数字可以直接抄进来**。
- **两个结构性的发现**：原版的 `table_objects` 组是一张**对象清单**（类型码 + 资源组号），`1000/1010` 是**墙**（64 段）、`1005` 是保险杠（**7 个**）、`1019/1006` 是红/黄靶（13 + 9 = **22 个**）——**比"最小可玩弹球"的设想大一个数量级**。

⚠️ **只参考几何数据，不引入任何资源**：坐标是**数据**，照抄；位图与音效一律不做——本作「零外部素材」的口径不变。

## 三条与传统小游戏不同的口径

- **几何全部程序化生成**，零外部素材（延用 `05` / `10` 的口径）。台面轮廓是一份顶点数据，改布局 = 改数据。
- **物理是混合的**：球与静态几何走 Jolt，**flipper 的冲量由代码手写**。分工与理由是这款的成败点，见技术规格书 §4。
- **复刻的是台面，不是规则**：机关会照原样摆，但它们**做什么**由本作自己定（原版的军衔晋升、六种任务、multiplier 链一律不做）。

## 视觉与配色

- **深色台面 + 自发光机关**：台面本体压暗（深蓝紫），机关用高饱和色点亮。玩家要在球高速掠过时一眼分辨"这是保险杠还是弹弓"——靠颜色，不靠形状细节。
- **球必须带高对比纹样**（棋盘格）。纯色球转与不转在画面上完全一样，而**自转是玩家读速度的唯一线索**——球滚得越快，纹样转得越急。
- **四种机关四种色**，一色一义，全程不换：

  | 元素 | 颜色 | 语义 |
  | --- | --- | --- |
  | 保险杠 bumper | 洋红 `#E94560` | 撞了得分最高的那个 |
  | 弹弓 slingshot | 琥珀 `#FFB703` | 会主动把球踢开 |
  | flipper | 青 `#4ECDC4` | 你能动的东西 |
  | 球 | 白 `#F2F5F7` | 白得发亮，全画面最亮的一点 |

- **超级作弊的绿色 `#00E676`** 与项目约定一致（详见"键位"）。
- 台面底图（凹槽、装饰线）用**程序化线条**画，不做贴图。

## 音效（程序化合成，无外部素材）

- **撞保险杠**：清亮的金属"叮"，**音高随连续命中逐次上爬**——这一串音就是玩家的连击读数。
- **撞弹弓**：闷而短的"啪"（是踢，不是敲）。
- **flipper 抬起 / 落下**：一短一长的机械"咔嗒"，**两个 flipper 各自独立发声**，玩家闭着眼能听出自己在动哪一边。
- **球在台面上滚**：一层低音量的持续噪声，**音量随速度**。
- **发射**：弹簧释能的"咻"，随蓄力高低变化。
- **掉球**：下行长滑音。
- **破纪录**：比结算再高一层的一段音。

## 核心体验

- **操作**：
  - **左 flipper**：`A` 或 `←`（按住抬起，松开落下）。
  - **右 flipper**：`D` 或 `→`（同上）。左右各管一边，是弹珠台的基本姿势。
  - **发射**：`空格`（或**鼠标左键**）**按住蓄力，松开弹出**。蓄力越久越快。
  - **`Esc`**：暂停菜单。
- **球的运动（玩家的心智模型，不必等于真实物理）**：
  - 台面是**斜的**（16°），球会自己往下滚——这是这款的节奏来源；
  - 球撞**保险杠**被弹开并加分，**回弹**（rebound）踢得比保险杠**更狠**——保险杠改变球的方向，回弹改变球的**去向**；
  - **flipper 打得越靠外段，球飞得越快**（离支点越远、线速度越大）——这是真实弹珠台的特性，也是"准点打"的技巧来源；
  - 球在台面上**是滚的**（不是滑的）：真机就是滚，而且自转是玩家读速度的线索。
- **节奏**：立项时按「慢 7 倍」设计（真机球速换算过来一帧走三个台面宽，根本没法看），实机两轮反馈都是「太慢」，最终**调到接近真机体感**——球加重、去掉 `linear_damp`、球速上限翻倍，**所有施加力的量同比例跟上**。⚠️ 这套架构有上限：再快球会一步跨过挡板而不被检出；**要更快得缩小整个台面的尺度**。
- **失败**：球从两个 flipper 之间掉出去（drain）→ **少一条球**，球回到发射道重新开始。三条球漏光 → 结算。
- **目标**：三条球里打出尽可能高的分。

## 台面机关（首版）

```
台面形状与原版一致：x ∈ [−8, 8]、y ∈ [−14, 13.88]（16 × 27.88），原版坐标直接沿用。

布局不在这里画——去看参考：
  · 截图          E:/SpaceCadetPinball/Screenshots/
  · 精确坐标      E:/SpaceCadetPinball/Doc/.dat dump.txt
  · 对象清单     同上的 table_objects 组（类型码 + 组号）

table_layout.gd 里的每一个数字，都对应那里的一段。
```

**复刻是"取骨架"，不是逐字抄。** 用户玩了一晚上原作后拍的板：**单层台面、砍掉一切"看不见"的东西**。下表左边是原版有什么，右边是这一版要做什么：

| 元素 | 原版 | 本作 | 说明 |
| --- | :---: | :---: | --- |
| 墙 wall | 64 段 | **54 段** | 圆形的墙（10 个）本作不支持，跳过。坐标照抄 |
| 保险杠 bumper | 7 | **7** | 位置与两种半径都照抄 |
| 靶 target | 22（黄 9 / 红 13） | **9（只留黄）** | 红靶全砍——它们偏右侧和下方，砍了右半边会空一点，接受 |
| 洞 sink | 4 | **4** | 球进去、停一下、再弹出来 |
| 滚过开关 rollover | 17 | **17** | 球从上面滚过去就计分亮灯。**没有实体，但让台面"有反应"** |
| kicker | 2 | **2** | 主动把球踢出去 |
| 单向门 one-way | 9 | **0** | 行为要额外状态，收益低 |
| 门 gate / trip / 旗帜 | 2 / 5 / 2 | **0** | 细碎，玩家几乎感觉不到 |
| 坡道 ramp | 2 条 + 1 洞 | **0** | ⚠️ **最大的一刀**。坡道意味着球离开台面这个平面，而整套混合物理都建立在"球在平面上"——见技术规格书 §12 |
| 灯 light | 140+ | **少量自发光点** | 纯装饰，不参与逻辑 |
| 军衔 / 任务 / multiplier | 有 | **0** | 复刻台面不复刻规则 |

**剩下的就是这一版要做的**：墙 + 7 保险杠 + 9 靶 + 4 洞 + 17 滚过开关 + 2 kicker + flipper + 发射道 + drain。

## 界面

- **主菜单**：标题、`START`、`QUIT`。从 hub 进入先看到它。
- **游戏中 HUD**：左上**分数**、右上**剩余球数**。分数是这款唯一的进度，必须一眼读得出。**最高分不占游戏画面**——它只在主菜单和结算卡上出现，玩的时候用不着看。
- **暂停菜单**（`Esc`）：`RESUME` / `RESTART` / `QUIT TO MENU`。
- **结算**：三条球用完后显示本局得分与最高分——破纪录时最高分那一行改成 `NEW RECORD`。**`空格` 再来一局，`Esc` 回主菜单**，两条都写在卡上。

## 键位

三个全局键按项目约定接上：

- **`P`（`debug_toggle`）只读叠加**：把**两类碰撞几何分开画**——Jolt 管的静态几何用亮黄 `#FFE94A` 线框，**手写管的 flipper 判定范围用另一个颜色**（含**上一帧的姿态**，扫掠区间一眼可见），再加球的速度矢量。纯诊断，不改变任何玩法。
- **`[`（`cheat_toggle`）**：**flipper 加长**（长度 ×1.6）——挡板更长，更容易救到球。与 `07-breakout` 的"加宽挡板"同型。
- **`]`（`super_cheat_toggle`）**：**永不掉球**——球越过 drain 线时被弹回台面（而不是送进发射道，那样反而要重新发射），球的**纹样变荧光绿 `#00E676`**（画在球身上，因为被接管的是球）。
- 三者**彼此独立**；`[` 与 `]` 在**每局开始 / 重开时复位**。

## 验收标准

- [ ] 从 hub 进入后看到**主菜单**；`START` 进游戏，`Esc` 回 hub，`QUIT` 退出程序。
- [ ] 进游戏后球停在发射道底部，HUD 显示 `3` 条球。
- [ ] **按住发射键蓄力、松开弹出**；蓄满与蓄一丝的初速度明显不同。
- [ ] 球的**发射道上升段不出轨、不穿墙**（这是全程最快的一段）。
- [ ] `A`/`←` 与 `D`/`→` 分别抬起左、右 flipper；**松手即落下**。
- [ ] **flipper 能把球打飞**：球以明显高于自由落体的速度被弹出，且**打到外侧段比内侧段飞得远**。
- [ ] **高速球不会穿过 flipper**（含 flipper 正在旋转时）。
- [ ] 球撞保险杠被弹开并 **+100**，撞弹弓被踢开并 **+50**。
- [ ] 球在台面上**往下滚**（不是停着不动、也不是飘在空中）；**纹样转得起来**。
- [ ] 球从底部缺口漏下 → **剩余球数 −1**，球回到发射道；剩 0 条时进结算。
- [ ] 结算显示本局得分，与最高分对照；破纪录时打出 `NEW RECORD`。
- [ ] **最高分写入存档**：退出游戏再进，主菜单上的最高分还在。
- [ ] 存档文件**不存在 / 损坏 / 版本不符**时，游戏照常启动（回退到空存档），不崩、不报错中断；**后两种在菜单上明说 `SAVE UNREADABLE`**，不把 0 当成真有人打过的最高分。
- [ ] `Esc` 分层正确：主菜单→hub、游戏中→暂停菜单（继续/重开/回主菜单）。
- [ ] 按 `P` 出现只读叠加（两类碰撞几何 + 速度矢量）；再按一次**立即消失**。
- [ ] 按 `[` 后 flipper 明显变长；开新局自动复位。
- [ ] 按 `]` 后**球再也漏不下去**，纹样变绿；开新局自动复位。
- [ ] 无素材导入报错；所有调参走 `pinball.cfg`，代码零魔法数。

## 范围与非目标

- **只做这一张台面**。不做台面编辑器，不做多张台面——布局是 `table_layout.gd` 里的一份顶点数据（见技术规格书 §5）。
- **复刻台面，不复刻规则**：原版的**军衔晋升、六种任务、multiplier / jackpot 链、多球**一律不做。机关照原样摆，但它们**做什么**由本作自己定。
- 不做：球的旋转技巧（nudge / 抬台）——**不允许玩家推动台面**。
- 不做任何物理仿真学意义上的"真实性"追求：**手感优先于真实**（与 `10-marble-race` 同一条口径）。
- **不引入原版的任何资源文件**：坐标是数据，照抄；位图（台面印刷、机关贴图）与音效一律自己做或不做。本作「零外部素材」的口径不变。
