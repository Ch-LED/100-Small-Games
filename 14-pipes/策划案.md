# 14-pipes — 策划案

## 定位

一款管道游戏，**四种玩法**。三种铺在同一个管道网格上，一种另外算。

| 模式 | 玩法 | 操作 |
| --- | --- | --- |
| **LINK** | 网格上散布成对的同色圆点，把每一对连起来 | 按住从圆点拖出 |
| **TURN** | 网格里是现成的水管，转它们让管口两两对接 | 左键顺时针、右键逆时针 |
| **SHIFT** | 水管方向固定，但可以整行整列挪 | 横拖 = 挪行，竖拖 = 挪列 |
| **SLIDE** | 水管方向固定，网格里有空格，把管子滑进空位 | 按住管子朝空位拖 |

**四种模式的题目全部程序化生成，而且全部不需要求解器**。做法都是同一个套路：**先构造一个已经"通了"的局面，再用玩家自己拥有的那个操作去打乱它**。打乱用的操作全部可逆（转四次等于没转、整行挪绕回原处、滑动留下的空位就在原处），所以**反向做一遍就是解法**——有解是构造出来的，不是搜出来的。

> **名字的由来**：用户点的名字是「接水管」。做完第一款（LINK）后用户澄清他要的其实是旋转那种，于是**「接水管」让给了 TURN 模式**，整款游戏改叫 **「管道」**（slug 仍为 `pipes`）。

## 视觉与配色（全部代码生成，无外部素材）

**LINK**：
- 深色棋盘 + 鲜艳的管道色（每条线一种明快的颜色，线与点同色）；圆点粗、线细；**连上的点变空心**；格子之间一层很淡的网格线；鼠标所在格描边。
- `[` 的提示路径是**青色**。

**TURN / SHIFT / SLIDE**：
- 管子是**中性的浅灰蓝**，一格一根：中心一个方块，朝每个开口伸出一段。
- **每个开口两两对接的那一格会变亮**（青色）——不用数就知道还剩多少。
- 空格不画东西；鼠标悬停时空格描虚线、有管子时描实底。
- `[` 的提示在底色上淡淡画出答案的形状。

## 音效（程序化合成，无外部素材）

**LINK**：拖出一格（音高随这一笔长度上行）、连通（上行两音）、清除（下行滑音）、按了没用（低音）、过关（上行四音）、破纪录（上行三音）。

**TURN / SHIFT / SLIDE**：转动/挪动（短促 tick）、一键应用答案（上行两音）、撤销（下行滑音）、过关与破纪录同上。

## 界面

四屏，整屏替换（与 10–13 同构）：

- **主菜单**：标题 + **四个模式的按钮**，每个下面一行是"怎么操作 + 打到第几关"；`BACK TO HUB`。
- **对局**：顶栏 `LEVEL n / TIME mm:ss / 模式名 / 读数`（LINK 报 `JOINED x/y  FILLED n/m`，其余三个报 `LOOSE n  PIECES m`）；中央棋盘；底部只有一行 `ESC MENU`。
- **暂停**（`Esc`）：`RESUME` / `NEW BOARD` / `QUIT TO MENU`，树真的暂停。
- **结算**：`模式名 LEVEL n CLEARED` + 用时 + 最佳（破纪录时绿色 `NEW BEST`）；空格进下一关。

## 核心体验

### LINK
- **从圆点上按住左键拖出去**；拖回自己走过的格子会**原路退回**；松手结束。**没连到对面的线保留着**。
- 不能交叉、不能穿过任何圆点。
- 过关 = **所有颜色连通 且 每格被覆盖**。

### TURN
- 点击转 90°，右键反向转 90°。
- 过关 = **每个开口都有另一个开口对着它，且没有任何开口朝着棋盘外**。

### SHIFT
- 拖动时，**手往哪边走，整行（或整列）的内容就往哪边挪一格**，挪出头的从另一头绕回来。
- 过关判定同 TURN。

### SLIDE
- 网格里有几个空格；按住一根管子朝空位拖，它滑过去。
- 过关判定同 TURN。

### 四个模式共有的
- **计时**：开局起计时，暂停不计。每个模式、每一关各记一个**最快用时**，通关即存档并推进该模式的进度。
- **`Z` 撤销**（一步；拖动整段算若干步）。
- **`Esc` 暂停。**

## 关卡与难度

**LINK** 用 `[levels]` 的 `sides` / `pairs`：5×5 的 4 色起步，加到 9×9 的 9 色。

**TURN / SHIFT / SLIDE** 共用同一张 `sides`（棋盘尺寸），难度来自 `[net_levels]` 的 **`shuffle_steps`**——打乱的步数，步数越多离解越远。SLIDE 另有 `slide_gaps`（空格数）。

**表走完就重复最后一行**，所以永远有下一关。

## 作弊键与调试键

**这一款不再把按键写在屏幕上**——作弊是留给人自己发现的，一张"按什么键"的清单会把棋盘变成说明书（DECISION_LOG 100）。

- **`P`（`debug_toggle`）**：只读叠加层，画在棋盘左侧的空白带里——模式、关卡、边长、管件数、空格数、**还没接上的开口数**、是否已接通、撤销栈深度、提示开关、鼠标所在格与其管件掩码、本关最佳。**它只是读数，一个格子都不改。**
- **`[`（`cheat_toggle`）**：**显示答案**。LINK 画出某一条颜色的完整路径（每按一次换下一条）；其余三个模式在底色上淡淡画出答案里每根管子的朝向。生成器手里本来就有答案，所以它是精确的。
- **`]`（`super_cheat_toggle`）**：
  - LINK：**允许线压线**（交叉处压白片，但仍穿不过圆点）。
  - TURN / SHIFT / SLIDE：**把整个盘一次性变成答案**——拆掉的是这三个模式赖以为生的那条约束："进度只能靠一次转一格、挪一行、滑一格"。

## 验收标准

- [ ] 从 hub 进入即见主菜单，四个模式各显示操作说明与进度；`Esc` 回 hub。
- [ ] 四个模式各自能从第一关开始；**下一关按模式各自推进**；存档按模式分开。
- [ ] **LINK**：从圆点拖出能画线；拖回自己走过的格子会退回；连不上时线条保留；不能压别的颜色、不能穿点；全连通 + 全覆盖才过关。
- [ ] **TURN**：左键顺时针、右键逆时针；转到所有开口对接才过关。
- [ ] **SHIFT**：横拖挪行、竖拖挪列，**方向跟手**，挪出头的从另一头绕回来；所有开口对接才过关。
- [ ] **SLIDE**：网格里有空格；能把管子拖进空位；所有开口对接才过关。
- [ ] 每个模式过关后进结算，用时进该模式该关的最佳成绩；空格进下一关。
- [ ] `Z` 撤销上一步；`Esc` 暂停且时间停止。
- [ ] 按 `[` 显示答案（淡色，再按一次关掉），**开局复位为关**。
- [ ] 按 `]` 后：LINK 能压线（但仍穿不过圆点）；其余三个**整盘变成答案并立即判定通关**；**开局复位为关**。
- [ ] 按 `P` 显示读数、再按消失，且**读数一个格子都不改**。
- [ ] **屏幕上没有任何按键提示**——底部只有 `ESC MENU`，作弊键的存在不出现在界面上。
- [ ] 存档文件不存在 / 损坏 / 版本不符三种情况都能启动，菜单上明说 `PROGRESS UNREADABLE`。
- [ ] 无素材导入报错；所有调参走 `pipes.cfg`，代码零魔法数。

## 范围与非目标

- 不做：桥（Flow Free 续作那种"从下面穿过去"的正经交叉机制）——LINK 的 `]` 是**直接重叠**。
- 不做：关卡选择画面、星级评价、步数统计、每日挑战。
- 不做：提示的"下一步"（只给整张答案，不做逐步引导）。
- 不做：触屏手势（全线鼠标拖拽）。
- 不引入任何外部美术/音频素材。
