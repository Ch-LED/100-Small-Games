# 04-snake — 策划案

## 定位

经典贪吃蛇：在网格场地里操控一条不断变长的蛇吃食物，撞墙或咬到自己即结束。不做玩法创新，只把手感、反馈与节奏做干净。图形全部由 `ColorRect` 纯色块构成（无外部素材），音效全部程序化合成——与 01-pingpong 同一路线。

## 视觉与配色（全部代码生成，无外部素材）

- 场地：深蓝黑背景，中间一块略亮的**棋盘面板**，面板上覆一层很淡的**网格线**。
- 边界：面板四周一圈亮色**边框**（撞墙处，需可见）。
- 蛇身：绿色方块阵列，方块之间留 2–3px 缝隙以看出节段；**蛇头**用更亮的黄绿色区分。
- 食物：红色方块，带缓慢**呼吸脉冲**（缩放 0.75–1.0 往复）。
- 顶部一条信息带：分数、关卡、长度居中偏左，最高分靠右。

## 音效（程序化合成，无外部素材）

启动时用代码合成 PCM 到 `AudioStreamWAV`，播放走 `AudioStreamPlayer` 池：

- **吃食**：短促方波双音交替（像 "tick-tock"），每次吃食物换一下音高。
- **升级**：上行三音小动机。
- **死亡**：下行音阶。
- **开局**：一声柔和低音起手。

## 背景音乐（程序化合成，无外部素材）

一段**循环的愉快小调子**，让人愿意在里面多待一会儿：C 大调、128 BPM、4 小节 ≈ 7.5 秒一循环，和弦走 I–IV–V–I，末小节落回主音，所以接回开头听不出接缝。方波主旋律 + 三角波低音（低音走"蓬-恰"的跳动感），音量压在音效之下。**开局起播、死亡停播**，重开再起。

## 作弊键

- **`[`（`cheat_toggle`）**：开关**穿墙**——蛇从一侧走出边界后从对面回来，而不是死。
- 视觉双保险：**边框变暗**（边框本来就是"死亡面"，不再致命时看着就该不一样），并闪一下 `WALL PASS ON / OFF` 提示。
- **每次开局自动关**：新一局永远按真实规则起手，不留隐形残留。
- **`]`（`super_cheat_toggle`）**：**食物自己送上门**。每一步食物朝蛇头走一格（先补差距大的那个轴，免得只沿一条轴爬），不吃就不动。食物**不会走进蛇身、也不会出界**，所以被围住时就停下——那通常已经贴着蛇头了。
  - **食物变成绿色**（就是吃的那一块变绿，很容易看出来），并闪一句 `THE FOOD COMES TO YOU / FOOD STAYS PUT`。
  - **同样每次开局自动关**。

## 核心体验

- **操作**：WASD 或方向键控制四方向。**按键即刻记录方向意图，到下一格才真正转向**；不允许 180° 掉头（会咬到自己，也不符合经典手感）。
- **推进**：蛇按固定时间间隔走一格（`base_interval` 秒/格），不是逐像素移动。间隔随关卡变短（有下限），节奏越来越紧。
- **食物**：随机落在**空格子**上。吃到 → 蛇长 `growth_per_food` 节、加分、换下一个位置。
- **死亡**：撞到面板边界（可配置为穿墙）或咬到自己身体 → 结束，播放死亡音，显示结算。
- **自咬豁免**：同时刻尾巴会让出当前格，所以"头进到尾格"不算死（除非这一步在增长）。
- **关卡**：每吃 `foods_per_level` 个食物升一级，蛇速加快；达到 `level_cap` 后封顶。
- **无限对局**：结束后可按键重开，局面分数归零，最高分按会话累积。

## 界面

- 顶部信息带：`SCORE` / `LEVEL` / `LENGTH` / `BEST`（最高分为本次运行内记录）。
- 中央覆盖文字：开局 `READY!`、结束时 `GAME OVER / PRESS SPACE`，作弊键切换时闪 `WALL PASS ON / OFF`（超级作弊闪 `THE FOOD COMES TO YOU / FOOD STAYS PUT`）。

## 验收标准

- [ ] 从 hub 进入即见棋盘、蛇（3 节，朝右）、一个食物，短暂 `READY!` 后开始走。
- [ ] WASD 与方向键都能转向；**不能 180° 掉头**。
- [ ] 吃到食物蛇变长、分数 +10、音效响、食物换到新的空格。
- [ ] 撞墙 / 咬到自己 → 死亡音 + 结算画面；按空格重开。
- [ ] 吃满 5 个食物升一级，格子间隔明显变短；到上限后不再加快。
- [ ] 尾巴让位的那一格可以安全进入（不误判死亡）。
- [ ] 按 `P`（`debug_toggle`）显示**相邻三格的生死提示**（红=会死、绿=安全），只读、不改玩法。
- [ ] 按 `[`（`cheat_toggle`）开关穿墙：边框变暗、提示 `WALL PASS ON`，此时从边界走出去会从对面回来；再按一次恢复；**重开一局自动关**。
- [ ] 按 `]`（`super_cheat_toggle`）开关"食物送上门"：食物变绿 + 提示，此后每一步朝蛇头挪一格（**不吃就不动、绝不进蛇身/出界**）；再按一次恢复；**重开一局自动关**。
- [ ] 全程有循环背景音乐（开局响、死亡停、重开再响），音效叠在音乐之上仍清晰。
- [ ] `Esc` 返回 hub。
- [ ] 无素材导入报错；所有调参走 `snake.cfg`，代码零魔法数。

## 范围与非目标

- 不做：关卡地图/障碍物、传送门玩法、双人、皮肤系统、道具。
- 不做排行榜持久化（最高分只在本次运行内）。
- 不引入外部美术/音频素材。
