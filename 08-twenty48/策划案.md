# 08-twenty48 — 策划案

## 定位

经典 2048 复刻：4×4 棋盘上朝四个方向推，相同的数字相撞合并，每走一步冒出一个新块，目标是拼出 2048。规则完全照搬原作，不做变体。图形全部由 Godot 的 **`Panel` + `StyleBoxFlat`（圆角）** 构成，**无外部素材**；音效全部程序化合成。

> **目录 slug 用 `twenty48` 而不是 `2048`**：`CONSTITUTION.md` 一要求 slug 一律**英文小写短横线**，纯数字不算"英文"。游戏展示名仍由 `meta.json` 给出 —— 菜单里显示的就是 **2048**。若你更想要 `08-2048/2048.tscn`，说一声即可改（见 DECISION_LOG 034）。

## 视觉与配色（全部代码生成，无外部素材）

- **沿用原作的浅色主题**：米白底、灰褐棋盘、圆角方块。2048 的识别度就来自这套配色，改成深色会变成"另一个游戏"。（若想要深色，改 `twenty48.cfg` 的 `bg_color` / `panel_color` 即可。）
- 数字方块按**暖→亮**递进上色（2 是米色，64 是砖红，2048 是亮金），与原作一致。
- 格子是 **`Panel` + `StyleBoxFlat`（圆角）**，数字是叠在上面的 `Label`；**16 个格子是场景里的固定结构，由 `GridContainer` 排布**——位置不用代码算。
- 字号按位数分档（1 位数最大，4 位以上最小），保证数字始终装得下。

## 音效（程序化合成，无外部素材）

- **滑动**：短促低音 click（只在本步确实有位移时响）。
- **合并**：方波短音，**音高随合并出的数值递增**（2 → 4 → 8 …每翻倍升半音），是原作的听觉标志。
- **凑出 2048**：上行小动机。
- **结束**：下行三音。
- **开局**：一声柔和起音。

## 核心体验

- **操作**：方向键 `↑`/`→`/`↓`/`←` 或 `W`/`D`/`S`/`A`，每按一次走一步。
- **合并规则**（原作契约）：同一方向上的方块依次靠拢，**相同的两块合并成一块双倍**，**每块一步内最多合并一次**（所以 `2 2 2 2` 向左变成 `4 4`，不是 `8`）。
- **得分**：每次合并，加上**合并出的那个数值**。
- **新块**：每走**有效**的一步（棋盘确实变了）在随机空格冒出一块 —— **90% 是 2，10% 是 4**。
- **结束**：棋盘填满**且**四邻再无相同数字可合 → 结算。
- **达成 2048**：飘一句提示，**不结束**，可以继续往更大的数字推；HUD 记下本局最大块。
- **最高分**：本次运行内累积。

## 界面

- 顶部：`SCORE`、`BEST`、`MAX`（本局最大方块数值）；作弊开启时右上角显示 `NO SPAWN`。
- 中央覆盖文字：`2048`（标题）、`GAME OVER`、`PRESS SPACE`。
- 棋盘下方的提示条：`PRESS SPACE TO START` / 达成 2048 的提示。

## 作弊键与调试键

- **`[`（`cheat_toggle`）**：开关**不再冒新块**（`NO SPAWN`）。2048 里最实在的作弊——没有随机干扰，局面就完全由你的走法决定，想拼多大多大。开启时 HUD 常驻 `NO SPAWN`，且切换时飘一句提示。
- **`]`（`super_cheat_toggle`）**：**冒出来的新块永远等于场上最大的那个数**（`MAX SPAWN`）。于是每滑一下多半就有东西能并，2048 很快就到——这个作弊故意做得很荒唐，荒诞感本身就是笑点。HUD 上它与 `NO SPAWN` **并列显示**（两个作弊互相独立、可以同时开），`MAX SPAWN` 用超级作弊的统一绿色。
  - 空盘时场上最大是 0，所以**开局那两块照常是 2 / 4**，不会一上来就给你个 64。
- **`P`（`debug_toggle`）**：只读读数——棋盘下方一行显示 `MOVES`（走子次数）、`EMPTY`（空格数）、`MAX`，以及**四个方向哪些还能走**（能走的亮绿、走不动的暗红）。用来回答"我按了方向键怎么没反应"。

## 验收标准

- [ ] 从 hub 进入即见空棋盘，按空格开局并出现两块（2 或 4）。
- [ ] 按 `]`（`super_cheat_toggle`）后**新冒出来的块永远等于场上最大的数**（HUD 显示绿色 `MAX SPAWN`，可与 `NO SPAWN` 同时开、并列显示），开局那两块仍是 2 / 4；再按一次恢复随机；**重开一局自动关**。
- [ ] 方向键 / WASD 都能走；四个方向都符合原作的合并规则，`2 2 2 2` 向左得 `4 4`。
- [ ] 每次合并加上合并出的数值；只有**棋盘确实变了**才冒新块。
- [ ] 新块 90% 是 2、10% 是 4；空格用尽时不再冒新块。
- [ ] 棋盘填满且无处可合 → 结算，空格重开。
- [ ] 拼出 2048 时飘提示但不结束，可以继续玩。
- [ ] 按 `[` 后不再冒新块且 HUD 常驻 `NO SPAWN`，再按还原；重开一局自动关。
- [ ] 按 `P` 显示读数与四方向可行标记，且**关掉后立即消失**。
- [ ] `Esc` 返回 hub；无素材导入报错；所有调参走 `twenty48.cfg`，代码零魔法数。

## 范围与非目标

- 不做：撤销、动画滑动（原作网页版有，此处按"瞬间就位"）、排行榜持久化、非 4×4 棋盘尺寸、道具/干扰块。
- 不做**触屏滑动**（键盘游戏）。
- 不引入任何外部美术/音频素材。
