# 07-breakout — 策划案

## 定位

经典 Breakout / Arkanoid 复刻：底部一块挡板，弹球把上方成排的砖块打光。砖块越往上分越高，球速越打越快，掉球扣命。不做道具、不做 Boss，把「挡板接球的角度手感」和「碎砖的节奏」做扎实。图形全部由 `ColorRect` 纯色块构成（无外部素材），音效全部程序化合成——沿用 01-pingpong 的路线。

## 视觉与配色（全部代码生成，无外部素材）

- 场地：深色背景；左右与顶部三面一条**可见的边框**（球在这里反弹），底部敞开（球从这里掉下去）。
- 砖块：**8 行 × 14 列**的矩形阵列，行与行之间留缝。**每两行一个颜色**，从上到下由暖到冷（红 → 橙 → 黄 → 绿 → 青 → 蓝 → 紫 → 灰），一眼能看出"上面更值钱"。
- 挡板：底部一条水平亮色矩形。
- 球：浅色小圆，带轻微拖尾感（用拉伸的圆角矩形即可）。

## 音效（程序化合成，无外部素材）

启动时用代码合成 PCM 到 `AudioStreamWAV`，播放走 `AudioStreamPlayer` 池：

- **击砖**：短促方波，**音高按砖块所在行**——越靠上的行音越高（这是原作最有辨识度的反馈）。
- **击中挡板**：中音短方波。
- **撞墙**：更低一档的方波。
- **掉球**：下行小动机。
- **过关**：上行三音。
- **发球**：一声柔和低音。

## 核心体验

- **操作**：方向键 `←`/`→` 或 `A`/`D` 左右移动挡板；**也可以直接用鼠标**——移动鼠标接管挡板，一按方向键就交还键盘。
- **发球**：开局球吸附在挡板上；按空格朝上发出（角度在 cfg 范围内随机）。
- **反弹手感**：球打在挡板的哪一段决定回弹角度——越靠边角度越斜（`reflect_curve`）；并强制"与水平方向至少 22°"，杜绝贴着上下做水平死循环。
- **瞄准扇形**：球朝挡板下落时，挡板上半边浮出一个小扇形，**指示这一球会往哪走**。
  - 玩家其实一直有主动权（有充足时间把挡板摆到任意接触点），缺的是**看见映射的手段**——扇形补的就是这件事。
  - 扇形**不是精确答案**：它的张开角度由**球到挡板的曼哈顿距离**决定——球越近越收紧（近到几乎是一条线），越远越散。
  - 模糊是**诚实**的：球远时它可能先蹭墙或蹭砖，方向本来就不确定；那个随机 2° 的抖动也包在最小张角里。
  - 想回到原版那种"盲打"手感，把 `aim_guide.enabled` 关掉即可。
- **速度**：每次击中挡板略微加速（有上限），过关再整体加速一档。
- **砖块**：击中即碎，按所在行加分（7/7/5/5/3/3/1/1）。打光全部砖块即过关，重建阵列并提速。
- **生命**：3 条。球从底部掉出扣 1 条，球重新吸附到挡板待发；命耗尽 → 结算。
- **最高分**：本次运行内累积。

## 界面

- 顶部：`SCORE`、`HIGH`、`LEVEL`，右上角残机数。
- 中央覆盖文字：`PRESS SPACE TO LAUNCH`、`LEVEL n CLEARED`、`GAME OVER / PRESS SPACE`。

## 作弊键与调试键

- **`[`（`cheat_toggle`）**：把挡板**加宽**（约 1.8 倍），接球立刻变容易；再按一次还原。挡板一变宽就能看出来，不需要额外提示。
- **`P`（`debug_toggle`）**：只读叠加——画出**球的碰撞圆与速度矢量**、**挡板与球所在活动范围的矩形轮廓**。用来核对"为什么这球这么弹"。

## 验收标准

- [ ] 从 hub 进入即见砖块阵列、挡板、吸附在挡板上的球；按空格发球。
- [ ] 方向键 / WASD 移动挡板；移动鼠标也能接管挡板；按方向键能交还键盘控制。
- [ ] 球撞左/右/上三面墙反弹，`P` 画出的边框与实际反弹位置一致。
- [ ] 击碎砖块加分（行分正确）、发声（音高随行变化）、砖块消失。
- [ ] 打光所有砖块 → 过关提示 → 新阵列 + 球更快。
- [ ] 球掉出底部 → 扣一条命、球回到挡板上待发；命耗尽 → 结算画面，空格重开。
- [ ] 任何速度下球都不会穿过挡板或砖块（包括高速贴边）。
- [ ] 按 `[` 挡板变宽、再按还原；按 `P` 显示碰撞圆与速度矢量，关掉后立即消失。
- [ ] 球朝挡板下落时出现瞄准扇形；球越近扇形越窄，越远越宽；**扇形指向与球真实的反弹方向一致**；球离开时扇形消失。
- [ ] `Esc` 返回 hub；无素材导入报错；所有调参走 `breakout.cfg`，代码零魔法数。

## 范围与非目标

- 不做：道具/掉落（扩板、多球、激光等 Arkanoid 元素）、不可破坏砖块、Boss 关、双人。
- **不做额外加命**：只有 3 条命，加分不再送命（与 03/05 不同，这里刻意保持原作的紧）。
- 不引入任何外部美术/音频素材。
