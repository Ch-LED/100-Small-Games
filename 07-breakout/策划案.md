# 07-breakout — 策划案

## 定位

经典 Breakout / Arkanoid 复刻：底部一块挡板，弹球把上方成排的砖块打光。砖块越往上分越高，球速越打越快，掉球扣命。不做道具、不做 Boss，把「挡板接球的角度手感」和「碎砖的节奏」做扎实。图形全部由 `ColorRect` 纯色块构成（无外部素材），音效全部程序化合成——沿用 01-pingpong 的路线。

## 视觉与配色（全部代码生成，无外部素材）

- 场地：深色背景；左右与顶部三面一条**可见的边框**（球在这里反弹），底部敞开（球从这里掉下去）。
- 砖块：**形状与行列数由关卡文件决定**（见下），行与行之间留缝。**颜色表示血量**：灰 = 打一下、蓝 = 打两下、金 = 打三下；被打掉一层就降一档颜色，所以损伤看得见。
- 挡板：底部一条水平亮色矩形。
- 球：浅色小圆，**身后拖一条逐渐变淡的线**（球本身始终是正圆，和碰撞圆一致——拖尾是**另画**的一条线，不参与碰撞）。
- 碎砖线屑：砖块被打碎时**朝球前进的方向**喷出一小撮短线段，**用那块砖自己的颜色**，约 0.34 秒内飞散并淡出。纯表现，不带碰撞。

## 音效（程序化合成，无外部素材）

启动时用代码合成 PCM 到 `AudioStreamWAV`，播放走 `AudioStreamPlayer` 池：

- **击砖**：短促方波，**音高按被打掉的那一层**——同一块砖越打到里面越响，**打碎的那一下永远是它最亮的一声**（这是原作最有辨识度的反馈）。
- **击中挡板**：中音短方波。
- **撞墙**：更低一档的方波。
- **掉球**：下行小动机。
- **过关**：上行三音。
- **发球**：一声柔和低音。
- **挥拍**：快速上行的短音，长度与挥出段对齐。
- **接球**：两声短促上行音——挥拍真的把球兜住了。

## 核心体验

- **操作**：方向键 `←`/`→` 或 `A`/`D` 左右移动挡板；**也可以直接用鼠标**——移动鼠标接管挡板，一按方向键就交还键盘。
- **发球**：开局球吸附在挡板上；**空格或鼠标左键**朝上发出（角度在 cfg 范围内随机）。**标题页与结算页同样可以点鼠标开始/重开**——鼠标已经在手里，就不该再去够键盘。游玩中空格/左键则是**挥拍**（见下）。
- **反弹手感**：球打在挡板的哪一段决定回弹角度——越靠边角度越斜（`paddle_curve`，边缘约 48°）；并强制"与水平方向至少 22°"，杜绝贴着上下做水平死循环。
- **挥拍**：**空格或鼠标左键**让挡板向上快速挥出、再降速收回，两段各有一个明确结果：
  - **挥出段**（约 0.16s）：碰撞位置整体上移约 54px——原本够不到的球能救回来，而且**球被加速狠狠弹回**（比平时快约 35%，速度上限同步放宽）。
  - **收回段**（约 0.22s）：碰撞位置落回原位，**此时落到挡板上的球不反弹而是被接住**，直接回到待发状态重新瞄准（连击清零——接住也算碰了挡板）。
  - 这一条补的是**方向决定权**：弧面只让手感更斜，挥拍才是一个"我现在就要打这一下"的动作。
  - 挡板的**视觉**是快速冲出、缓缓落回；**碰撞位置**则是阶跃的（挥出段整个在顶上、收回段整个在底部），不跟着动画连续滑动——会滑的箱子意味着玩家可能撞上一个"和它看见的挡板不在同一位置"的东西。
- **速度**：每次击中挡板略微加速（有上限），过关再整体加速一档。
- **关卡**：一关一个文本文件（`07-breakout/levels/NN.txt`），**写下来就是砖墙的样子**——第一行是最上面一行，`.`（或空格）是空的格子，`1`-`9` 是**这块砖要打几下**。**行数与列数都来自文件**，所以关卡可以有洞、有形状、有厚薄。五关打完后回到第一关继续，速度照旧递增。
- **砖块**：**数字就是血量**，也是颜色（灰 1 / 蓝 2 / 金 3），被打掉一层就降一档。
  - **每打一下都计分**，而且**越外层越值钱**（金 9 / 蓝 5 / 灰 3），所以一块三层砖的总分是三次之和；**但只有把砖打碎才算进连击**——连击数的是"碎了几块砖"，蹭掉一层不算。
  - 打光全部砖块即过关，读下一关的文件。
- **连击**：**从上次碰到挡板起连续碎了多少块砖**，每 `combo_step`（3）块把得分倍率抬高一档（封顶 `combo_max` = ×5），**击砖音高也随之逐个上爬**，HUD 在倍率超过 ×1 时显示 `COMBO n xN`。
  - 碰到挡板、掉球、过关、重开都会**清零**——连击的代价就是"别让球回来"。
  - 这一条是为了让**砖层后面那条窄缝**（球在墙和砖之间反复快速横跳）从死时间变成高光：现在那串连跳会变成一段越来越高的音阶和一路 ×5 的分数。
- **生命**：3 条。球从底部掉出扣 1 条，球重新吸附到挡板待发；命耗尽 → 结算。**挥拍收回段接住的球不算掉球**，直接回到待发。
- **最高分**：本次运行内累积。

## 界面

- 顶部：`SCORE`、`HIGH`、`LEVEL`，右上角残机数。
- 中央覆盖文字：`PRESS SPACE TO LAUNCH`、`LEVEL n CLEARED`、`GAME OVER / PRESS SPACE`。

## 作弊键与调试键

- **`[`（`cheat_toggle`）**：把挡板**加宽**（约 1.8 倍），接球立刻变容易；再按一次还原。挡板一变宽就能看出来，不需要额外提示。
- **`P`（`debug_toggle`）**：只读叠加——画出**球的碰撞圆与速度矢量**、**挡板与球所在活动范围的矩形轮廓**。用来核对"为什么这球这么弹"。

## 验收标准

- [ ] 从 hub 进入即见砖块阵列、挡板、吸附在挡板上的球；按空格发球。
- [ ] 方向键 / WASD 移动挡板；移动鼠标也能接管挡板；按方向键能交还键盘控制。
- [ ] 球撞左/右/上三面墙反弹，`P` 画出的边框与实际反弹位置一致。
- [ ] **关卡来自文件**：砖墙的形状与行列数跟 `levels/NN.txt` 写的一致（改文件就能改关卡）；打完一关读下一个文件，五个文件用完后回到第一关。
- [ ] **多层砖**：金的要打三下、蓝的两下、灰的一下；打一下**颜色降一档**、砖还在、球照样弹开；只有打碎才涨连击。
- [ ] 击碎砖块加分、发声（越打到里面音越高、碎的那一下最亮）、砖块消失，并**喷出一撮同色线屑**（约 0.34s 内散尽）。
- [ ] 球在场上时身后有**渐隐的拖尾**；球吸附在挡板或停在场外时拖尾立刻消失（发球不会拉出一条横贯场地的线）。
- [ ] 打光所有砖块 → 过关提示 → 新阵列 + 球更快。
- [ ] 球掉出底部 → 扣一条命、球回到挡板上待发；命耗尽 → 结算画面，空格重开。
- [ ] 任何速度下球都不会穿过挡板或砖块（包括高速贴边）。
- [ ] 按 `[` 挡板变宽、再按还原；按 `P` 显示碰撞圆与速度矢量，关掉后立即消失。
- [ ] 空格 / 左键挥拍：**挥出段**把落上来的球加速弹回、**收回段**把落上来的球**接住**并回到待发；挥拍进行中再按不会叠加；挥拍有音效。
- [ ] `Esc` 返回 hub；无素材导入报错；所有调参走 `breakout.cfg`，代码零魔法数。

## 范围与非目标

- 不做：道具/掉落（扩板、多球、激光等 Arkanoid 元素）、**打不碎的砖**（多层砖只是要打几下，不是打不掉）、Boss 关、双人。
- 关卡**手写**，不做随机生成，也不在 cfg 里写关卡——文件就是关卡（见核心体验）。
- **不做额外加命**：只有 3 条命，加分不再送命（与 03/05 不同，这里刻意保持原作的紧）。
- 不引入任何外部美术/音频素材。
