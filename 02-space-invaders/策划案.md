# 02-space-invaders — 策划案

## 定位

经典 Space Invaders 复刻：玩家在屏幕底部横向移动、向上射击，抵御逐层下压的敌人方阵。全部视觉来自 `assets/sprites.png`（aseprite 导出，27 帧，tag 划分）。

## 界面流程

1. **开始界面**：标题 + 三类敌人的分数注明（鱿鱼 40 / claude code 20 / 水母 10，可附 UFO 50–300）；背景由三种深蓝瓦片拼接而成；**按空格开始**。
2. **游戏内**：上方是敌人方阵，中下侧一排 4 个掩体，底部是玩家；左上角分数（像素字体，**六位补零**），右上角残机。
3. **结束**：残机归零，或敌人方阵压到玩家所在层 → 游戏结束。

## 核心机制

### 敌人方阵
- 共 **5 层 × 11 列 = 55 只**：第 1 层鱿鱼(40)，第 2–3 层 claude code(20)，第 4–5 层水母(10)。
- 每 tick 整阵横向移动一步；触边界后**下压一排**并反向。单只敌人被击毁不影响方阵步调。
- 方阵压到玩家所在层 → 立即结束。

### tick 计时器
- 敌人一切行动由 tick 驱动。**按剩余敌人数加速**：本关开始时最慢，随敌人减少加快，**剩最后两层时达顶峰**；进入下一关重置为较慢值，但因关数递增而整体更快。

### 敌人开火
- 每 tick 由**最前排**（最靠近玩家的那一排，逐列取最前）敌人尝试开火，每次随机两种模式之一，且**可能失败**。
  - **能量弹**（`plaz`）：弹速 = 玩家激光弹速度。
  - **飞镖弹**（`drat`）：弹速略慢于能量弹。

### 飞碟
- 顶部间歇横穿的高价值目标，击毁得 **50–300pt**（**只跳分数，不播爆炸特效**）。

### 玩家
- 底部左右移动；向上发射激光弹；**场上存在自己的子弹时不能再发射**（单发限制）。
- 被敌人子弹或敌机碰到：扣 1 条残机，原地复活并短暂无敌。

### 掩体
- 中下侧一排 **4 个**，由 6×6 瓦片拼成；每块瓦片承受 **4 次攻击**后消失。
- 玩家与敌人的子弹都会消耗掩体；**敌机方阵压到掩体所在行会吞掉掩体**。

### 关卡
- 清屏 → 进入下一关，**残机 +1**；每关敌人初始位置**下移一排**、tick 基准提升，且保证最底层敌人距底线至少两层。
- 残机归零 → 结束。

## 验收标准

- [ ] 开始界面有标题与分数说明，背景为三种瓦片拼接；空格进入游戏。
- [ ] 五层 11 列方阵就位，造型与分值正确；两帧动画在动。
- [ ] 方阵左右移动、触边下压；压到底层即结束。
- [ ] tick 随敌人减少加快，剩最后两层最快。
- [ ] 最前排发射两种弹；能量弹与玩家弹同速、飞镖弹更慢；开火有失败率。
- [ ] 击毁飞碟跳分数且无爆炸；击毁普通敌人有爆炸特效。
- [ ] 掩体四块、逐瓦片损伤、4 次消失；被敌机压到会吞掉。
- [ ] 左上分数六位补零、右上残机；被击中扣命并短暂无敌；清屏 +1 残机。
- [ ] 玩家单发限制生效；开始界面之外可 Esc 返回 hub。

## 范围与非目标

- 不做：音效、多武器、道具、联机、存档。只做一块干净的经典复刻。
- 所有调参数值集中 `space-invaders.cfg`，代码零魔法数。
