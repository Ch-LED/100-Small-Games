# 13-sudoku — 策划案

## 定位

经典数独：9×9 盘上填 1–9，每行、每列、每个 3×3 宫各出现一次。**三档难度，题目全部程序化生成**——先随机造一个合法终盘，再逐个挖洞，**每挖一格就验一次"解是否仍然唯一"**，验不过就把那一格填回去。所以每一局都是新题，且永远只有一个答案。图形全部由 `Control._draw()` 逐格绘制，**无外部素材**；音效全部程序化合成。

## 视觉与配色（全部代码生成，无外部素材）

- **深色盘面**，与 10–12 的基调一致：近黑的场地上放一块深蓝棋盘，格子之间细线、**九个宫之间粗线**——粗细分明的网格是数独一眼可读的前提。
- **给定数字与玩家填的数字颜色不同**：给出的是浅白（"石头"），自己填的是天蓝（"墨"）。一眼分得清哪些是题目给的、哪些是自己写的。
- **你正在看的那个格**有底色，**它所在的行、列、宫**有更淡的底色——这是读盘辅助，不是对错判断。
- 冲突（同行/列/宫出现重复数字）**标红**。
- 铅笔标记是格子里的 3×3 小数字；作弊键帮你算出的候选数是**青色**。

## 音效（程序化合成，无外部素材）

- **填入**：短音，**音高随数字大小递增**（1 最低、9 最高），所以耳朵能听出刚填的是几。
- **擦除**：低音短音。
- **铅笔**：更轻更短的音。
- **冲突**：低沉的短音——填出一个重复数字时响。
- **完成**：上行四音。
- **破纪录**：上行三音。

## 核心体验

- **操作**：方向键 / `WASD` 移动光标，`1`–`9` 填入数字，`Backspace` / `Delete` 清除，`Z` 切换**铅笔模式**。鼠标左键点格选中，**右键点格 = 选中并切换铅笔**。
- **给定格不可改动**：题目给出的数字不能被覆盖或擦除（按下去会响一声冲突音，不是静默失败）。
- **冲突只报"盘面自相矛盾"**：同一个数字在同行/列/宫里出现第二次时，相关格标红并计一次错误。**它不告诉你对错**——一个错但不重复的数字是安静的（那是解题的一部分）。
- **完成**：81 格填满且全盘无冲突即通关。唯一解保证这就等于解出来了。
- **计时**：开局起计时，暂停不计。三档难度各有自己的**最快用时**，通关即存档。

## 界面

四屏，整屏替换（与 10/11/12 同构）：

- **主菜单**：标题 + 三档难度（每档下面是自己那档的最快用时）+ `BACK TO HUB`。
- **对局**：顶栏 `难度 / TIME mm:ss / BLANKS n`，右上角叠着当前开着的开关（`PENCIL` / `CANDIDATES` / `ANSWER`）；中央棋盘；底栏一行键位提示。
- **暂停**（`Esc`）：`RESUME` / `NEW PUZZLE` / `QUIT TO MENU`，树真的暂停。
- **结算**：`SOLVED` + 用时 + 难度与错误次数 + 最佳（破纪录时是绿色 `NEW BEST`）。

## 作弊键与调试键

- **`P`（`debug_toggle`）**：只读叠加层，画在棋盘左侧的空白带里——最佳成绩、本次挖洞目标与实际挖到多少、给定/空的格数、冲突格数、**与答案不符的格数**、光标坐标与它的候选数、累计错误次数。**它只是读数，一个数字都不往盘上写。**
- **`[`（`cheat_toggle`）**：**把候选数直接显示出来**（`CANDIDATES`）。每格按"这一格还能填什么"自动算出候选并以青色显示，等于把铅笔工作全替你做了。这是"把这一局变简单"最直白的一种——排除法不再需要你自己算。
- **`]`（`super_cheat_toggle`）**：**光标选中哪个空格，那个格子就自己填上正确答案**（`ANSWER`，数字用超级作弊的统一绿 `#00E676`），「答案自己送上门」，与 04-snake 的食物送上门同型。它**不改变填格这件事本身**——该走的光标一步不少、盘面仍然要填满、仍然要合法——拆掉的只有"你得自己想出来"这条约束。
  - 被 `]` 填过的格子**带绿色标记**，即使关掉作弊也还认得出是谁写的；玩家自己擦掉重填则标记消失。
  - 三档难度、三档计时都**照常记录**——作弊是你的选择，成绩表不替你遮掩。

## 验收标准

- [ ] 从 hub 进入即见主菜单，三档难度各自显示最快用时；按 `Esc` 回 hub。
- [ ] 选一档开局，棋盘出现且题目**有且只有一个解**，光标落在第一个空格上。
- [ ] 方向键 / `WASD` 都能移动光标，且边缘会停住；鼠标左键点格能选中，右键点格切换铅笔。
- [ ] `1`–`9` 填入数字，音高随数字变化；`Backspace` / `Delete` 清除。
- [ ] 给定格不能覆盖、不能擦除。
- [ ] 同行/列/宫出现重复数字时相关格标红并计一次错误；擦掉后红色消失。**不重复但填错的数字不报。**
- [ ] `Z` 切铅笔模式，`PENCIL` 常驻 HUD；铅笔标记写在格子里的 3×3 位置，再按同一个数字取消。
- [ ] 按 `[` 后所有空格显示自动候选数（青色 `CANDIDATES`），再按还原；**开局复位为关**。
- [ ] 按 `]` 后光标移到的空格立刻被填上正确答案并标绿（`ANSWER`），再按还原；**开局复位为关**。
- [ ] 填满且无冲突即通关，进结算；用时进入该难度最佳成绩；**重开一局复位所有开关与计时**。
- [ ] 按 `P` 显示读数、再按消失，且**读数一个数字都不改动盘面**。
- [ ] `Esc` 打开暂停菜单且时间停止；`RESUME` / `NEW PUZZLE` / `QUIT TO MENU` 三条路都对。
- [ ] 存档文件不存在 / 损坏 / 版本不符三种情况都能启动，菜单上明说 `SAVE UNREADABLE`。
- [ ] 无素材导入报错；所有调参走 `sudoku.cfg`，代码零魔法数。

## 范围与非目标

- 不做：非 9×9 的盘面（4×4 / 6×6 / 16×16）、杀手数独、对角数独等变体。
- 不做：求解器提示（"下一步该看哪一格"）、自动检查、撤销栈。
- 不做**分区高亮外的数独技巧教学**（唯一候选、宫内唯一、X-Wing……）。
- 不做每日挑战、排行榜、云存档。
- 不引入任何外部美术/音频素材。
