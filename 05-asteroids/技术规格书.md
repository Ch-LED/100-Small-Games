```
├─ Hud (Control, hud.gd)

```

- **静态结构**（背景、各挂点、HUD 骨架、结算框）全部写在 `.tscn`。
- **动态内容**（星点、小行星、子弹、飞碟、爆散、残机图标）由代码 `instantiate()` 后挂进场景预留的容器。
- 节点访问一律 `@onready var _x: Type = $Path`（CONSTITUTION 五）。
- **矢量图形而非素材**：飞船/小行星/飞碟用 `Polygon2D`（填充）+ `Line2D`（轮廓），子弹用 `Polygon2D`——这些都是有明确语义的引擎节点，不是"用代码造等价物"。

## 4. 几何与环绕（`asteroids_field.gd`，`class_name AsteroidsField`）

- `SIZE := Vector2(1280, 720)`。
- `wrap_point(p) -> Vector2`：`fposmod` 逐轴归一化到 `[0, SIZE)`。**飞船、小行星、子弹都用它**——出哪边从对边回来。
  - 用 `fposmod`（而非"越界后一次性搬移"）意味着实体**在边界处就立刻换侧**，和原作一致：半出画面时另一半已在对边出现。
- `random_point(margin) -> Vector2`：场内随机点（留边距），供波次生成与飞碟选高度用。

## 5. 移动与手感

### 飞船（`ship.gd`，`class_name AsteroidsShip`）
- 状态：`position`、`rotation`、`velocity`（惯性）。
- **旋转**：`rotation += steer * rotate_speed * delta`（`rotate_speed` 度/秒，250 左右）。
- **推进**：`velocity += Vector2.RIGHT.rotated(rotation) * thrust_accel * delta`。
- **阻尼**：`velocity *= exp(-drag * delta)`（帧率无关）。**这是对原作的刻意偏离**——原版无阻尼、永远漂移；加了 `drag=0.45` 让它约 2.5s 内滑停，键盘操作才可控。想还原经典手感把 `drag` 设 0 即可。
- **限速**：`velocity` 超过 `max_speed` 时按比例缩回。
- **位移**：`position = AsteroidsField.wrap_point(position + velocity * delta)`。
- **开火**：受 `fire_cooldown` 与**同屏弹数上限 `max_bullets`** 双重限制；子弹从船头沿朝向射出。
- **底部喷焰**：`Flame` 是场景里的 `Polygon2D` 子节点，仅推进时可见（附轻微抖动）。
- 被击毁 → 隐藏自身并停用碰撞，由 `game.gd` 走死亡流程；`radius` 供复活点安全性检查。

### 子弹（`bullet.gd`，`class_name AsteroidsBullet`）
- 直线飞行 + **环绕**，存活 `lifetime` 秒后自毁（所以同屏数量天然有界，但仍显式卡 `max_bullets`）。
- 玩家弹与飞碟弹**同一个场景**，只是 `setup()` 给的碰撞层/掩码不同。

### 小行星（`rock.gd`，`class_name AsteroidsRock`）
- 三档尺寸（大/中/小），每档有自己的 `radius`、`score`、速度区间、自转区间（cfg 里三个并列的数组，按档索引取）。
- **外形**：`_build_outline()` 随机取 `vertices_min..vertices_max` 个顶点，每个顶点半径按 `jaggedness` **只向内**抖动（`r = radius × (1 − jaggedness × rand)`）→ 生成 `Polygon2D.polygon` 与闭合的 `Line2D.points`。**每块形状唯一**；填充与轮廓用同一组点，永远对得上。
  - ⚠️ **抖动只减不增是有意的**：这样碰撞圆恒**外接**于画出来的多边形——看起来碰上的那一发绝不会漏判。若允许顶点外凸，就会出现"视觉上已经接触、判定却没过"的憋屈情况（可参考 `P` 调试视图自行核对）。
- **运动**：匀速直线 + 自转（`rotation += spin * delta`）+ 环绕。
- **被击碎**：`shatter()` 记录自身档位与位置、发 `shattered(kind, position)` 信号、`queue_free()`。**子块由 `game.gd` 生成**（实体生命周期归控制器，与 02 的 enemy/ufo 同模式）。
- 命中判定用的 `radius` 与视觉多边形一致（多边形顶点就在该半径附近抖动）。

### 飞碟（`saucer.gd`，`class_name AsteroidsSaucer`）
- 从一侧横穿到另一侧后自行 `queue_free()`（**不环绕**，横穿即离场）。
- 每隔 `fire_interval` 开一次火：以 `aim_chance` 概率朝飞船当前位置瞄准（叠加一点随机角），否则纯随机方向。
- 可被玩家子弹击毁（发 `destroyed(score, at)`）；撞上飞船时双方消失。

## 6. 碰撞（分层，只由"探测方"解算）

`asteroids_layers.gd`（`class_name AsteroidsLayers`）定义位：

| 位 | 名称 |
| --- | --- |
| 1 | `SHIP` |
| 2 | `ROCK` |
| 4 | `BULLET` |
| 8 | `SAUCER` |
| 16 | `SAUCER_BULLET` |

**只有三类节点 `monitoring = true`**，其余一律 `monitoring = false` + `monitorable = true`，**保证每次接触只被解算一次**：

| 节点 | layer | mask | 解算内容 |
| --- | --- | --- | --- |
| 飞船 | `SHIP` | `ROCK \| SAUCER \| SAUCER_BULLET` | 撞小行星 / 撞飞碟 / 中飞碟弹 → 被击毁 |
| 玩家子弹 | `BULLET` | `ROCK \| SAUCER` | 击碎小行星 / 击毁飞碟 |
| 小行星·飞碟·飞碟弹 | 各自 | `0` | 只被探测，自己不探测 |

- **飞碟弹不探测**：它只 `monitorable`，由飞船的单侧判定负责——避免与飞船互相触发两次。
- **同帧抢杀的保护**：小行星有个"已被打碎"标志，`shatter()` 里立刻置位。飞船的解算**跳过已打碎的小行星**——不然"最后一刻打爆它却仍被撞死"会很憋屈。
- 碰撞形状一律 `CircleShape2D`，半径取各实体的 `radius`（与视觉多边形一致）。子弹半径很小，但速度 680 px/s 在 60fps 下每帧仅移动约 11px，**远小于最小目标半径 14px，不会穿隧**。

## 7. 配置 `asteroids.cfg`

**完整取值与注释以 `05-asteroids/asteroids.cfg` 为准**（唯一可信源）。分区职责：

| 分区 | 关键项 | 职责 |
| --- | --- | --- |
| `[field]` | `bg_color` `star_color` `star_count` `star_min` `star_max` `ship_color` `invuln_color` `thrust_color` `rock_color` `saucer_color` `bullet_color` | 配色、星点数量与大小 |
| `[ship]` | `rotate_speed` `thrust_accel` `drag` `max_speed` `radius` `lives` `fire_cooldown` `max_bullets` `invuln_time` `death_pause` `safe_spawn_radius` | 操控手感、残机、开火限制、重生与无敌 |
| `[bullet]` | `speed` `lifetime` `radius` `length` | 弹道 |
| `[rock]` | `radius` `score` `speed_min/max` `spin_min/max`（均为 3 元数组）、`level_speedup` `level_speedup_cap` `vertices_min` `vertices_max` `jaggedness` | 三档尺寸/分数/速度、每关提速、外形随机 |
| `[wave]` | `start_count` `count_step` `count_cap` | 波次块数曲线 |
| `[saucer]` | `first_delay` `interval_min/max` `speed` `radius` `score` `fire_interval` `aim_chance` `bullet_speed` `y_min` `y_max` | 飞碟出场节奏、火力与分值 |
| `[fx]` | `shards` `length` `duration` `spread` `size_scale`（3 元数组）`ship_scale` `ship_duration` | 爆散观感，按目标尺寸缩放 |
| `[beat]` | `slow` `fast` | 心跳节拍的最慢/最快间隔 |
| `[score]` | `extra_life` | 加命分数 |
| `[hud]` | `font_size` `margin` `lives_icon_scale` | HUD 字号、边距与残机图标大小 |

颜色以 6 位 hex 存，加载时 `Color.html` 解析。代码内**零调参魔法数**。

**三档数组一律以 `[大, 中, 小]` 的数组形式存在 cfg 里**（`radius=[46, 26, 14]` 这样），读成 `Array[float]` / `Array[int]`，按 `AsteroidsSettings.LARGE/MEDIUM/SMALL = 0/1/2` 取值。早先试过"三个独立标量键"，会让读取 helper 需要同时处理数组键与标量键两种形态、读写两头都绕，故统一成数组。

## 8. 对局（`game.gd`，`class_name AsteroidsGame`）

- 状态机 `State { TITLE, PLAYING, DYING, RESPAWN, OVER }`。
  - `TITLE`：飞船居中静止、显示标题与分数说明，空格开局。
  - `PLAYING`：读输入、驱动飞船、检查波次与飞碟。
  - `DYING`：飞船爆散、场地冻结 `death_pause` 秒。
  - `RESPAWN`：等待复活点安全（`safe_spawn_radius` 内无小行星），安全后重生并给 `invuln_time` 无敌；若生命已耗尽则进 `OVER`。
  - `OVER`：结算，空格重开。
- **波次**：`_spawn_wave(level)` 在**离飞船足够远的环带**上生成 `count` 块大石（`start_count + (level-1)*count_step`，封顶 `count_cap`），速度乘 `level_speedup^(level-1)`（封顶）。
  - 清空 → `_next_wave.call_deferred()`：**必须在 `call_deferred` 里做**（在子弹的物理回调链上直接重建会改动物理服务器）。
  - `_wave_pending` 防同帧多颗子弹触发两次。
- **计分**：加分数时检查是否跨过 `extra_life` 的整数倍 → 加命并播提示音。
- **心跳**：由剩余小行星数推出的进度决定节拍间隔（见 §9）。
- **无敌**：`[`（`cheat_toggle`）切换；开启时飞船轮廓改为 `invuln_color`，且**所有对飞船的伤害判定直接跳过**。每次开局复位为关。

## 9. 心跳节拍（紧张感的来源）

```
weight    = Σ SHATTER_WEIGHT[rock.kind]        # 场上还欠的"打碎次数"
progress  = 1 - weight / wave_start_weight     # 场上越空越接近 1
interval  = lerp(beat.slow, beat.fast, progress)
```

- `SHATTER_WEIGHT = [7, 3, 1]`（大 / 中 / 小）：**一块大石要彻底清掉需要 1 + 2 + 4 = 7 次打碎**（它自己、它的两块中石、四块小石），中石 3 次，小石 1 次。
- `wave_start_weight = 该波块数 × 7`（新波全是大的），在 `_spawn_wave()` 里直接按公式算定，**不去数当前子节点**——上一波 `queue_free()` 还没落地的岩石会污染计数。
- ⚠️ **为什么不用"剩余块数"**：打碎一块大石会生成**两块**中石，块数从 4 变 5，**不降反升**，心跳会突然变慢。用"还欠多少次打碎"才是**严格单调递减**的：7 → 6 → 5 → …（一条断言专门钉这个不变式：大石 7 → 两块中石 6 → 一块中石加两块小石 5）。
- `beat.slow`（默认 1.05s，满场时）→ `beat.fast`（默认 0.26s，快清空时）。
- 每 `interval` 秒播一声，两声一组交替音高（经典的"咚-咚"）。
- 每条命、每一波都从 `wave_start_weight` 重新算起。

## 10. 程序化音频（`asteroids_audio.gd`，`class_name AsteroidsAudio`）

启动时合成 PCM 到 `AudioStreamWAV`（22.05kHz / 16-bit / 单声道），`AudioStreamPlayer` 池播放（一次性音效）+ 专用常驻播放器（循环音）。

| 事件 | 音色 | 触发 |
| --- | --- | --- |
| 开火 | 方波 880→280Hz / 0.07s | 玩家开火 |
| 推进 | 低通噪声**循环**，低音量 | 按住推进期间起停 |
| 碎裂（大/中/小） | 白噪声爆响，三档音高与时长递减 | 小行星被打碎 |
| 飞船被毁 | 长噪声 + 下行音，约 0.6s | 飞船遭撞击 |
| 飞碟 | 两音交替**循环**颤音 | 飞碟存活期间起停 |
| 心跳 | 两个低频短音交替 | §9 的节拍 |
| 加命 | 上行三音 | 跨过 `extra_life` |

- 噪声用 `_noise(duration, volume, smooth)`：白噪声加一个一极点低通（`smooth` 越大越闷），用于爆响与推进。
- 循环音（推进、飞碟）用 `AudioStreamWAV.loop_mode = LOOP_FORWARD` 并把 `loop_begin/loop_end` 铺满缓冲，首尾都落在包络零点上，**接缝无爆音**。
- 音频合成 helper（方波 / 扫频 / 加噪 / 包络）与 01/02/03/04 同源，**后续可整体抽到 `plugins/`**（DECISION_LOG 015 已备注，时机由用户定）。

## 11. 调试键与作弊键

- **`P`（`debug_toggle`）只读**：给每个实体画碰撞圆（`draw_arc` 描边），并给每块小行星画一支速度矢量箭头。**不改变任何玩法**，看到的即真实判定半径。
  - 实现：`Playfield` 之后的 `DebugDraw`（`Node2D`，`asteroids_debug.gd`）每帧接收控制器推来的只读快照（位置/半径/颜色/速度），启用时自行重绘。
  - ⚠️ **开关必须"出去也重绘"**：`_draw` 发出的绘制命令会被画布缓存，直到再次请求重绘才更新。若只在 `enabled` 为真时 `queue_redraw()`，**关掉的一瞬间会停在最后一帧**——看起来像"卡住了"而不是"关掉了"。所以 `enabled` 用带 setter 的变量：值一变就 `queue_redraw()`，`_draw()` 在 `enabled` 为假时不发任何命令，画布即被清空。（同一处理已在 `03-pacman/scripts/pacman_debug.gd` 存在，见 DECISION_LOG 029。）
- **`[`（`cheat_toggle`）作弊**：无敌，见 §8。飞船轮廓转 `invuln_color` 明确提示。
- 两个键都是**项目级输入动作**（`project.godot`），跨游戏共用。

## 12. 输入

复用项目级 `[input]`：`wasd_up/down/left/right`、`arrow_up/down/left/right`、`fire`（空格）、`debug_toggle`（`P`）、`cheat_toggle`（`[`）、`ui_cancel`（Esc）。

- 转向意图 = `wasd_left || arrow_left` → −1；`wasd_right || arrow_right` → +1（fallthrough 合并）。
- 推进 = `wasd_up || arrow_up`（**按住**持续推进，不是点按）。
- 开火 = `fire` 按住即按冷却与弹数上限尝试发射。

## 13. 风险 / TODO

| 事项 | 优先级 | 说明 |
| --- | --- | --- |
| 惯性与阻尼的手感 | 中 | `drag=0.45` 是刻意偏离原作的选择，需实机确认"可控但仍有惯性"；设 0 即还原经典漂移 |
| 复活点安全性 | 中 | `safe_spawn_radius` 偏小会一复活就死，偏大则等太久；需实机调 |

| 心跳节拍的干扰 | 低 | 若觉得吵，调 `[beat]` 两个间隔或直接把音量压下去 |
| 实体数量 | 低 | 波次封顶 11 块大石 → 最多约 44 块小石 + 子弹 + 飞碟，Area2D 数量可控 |
