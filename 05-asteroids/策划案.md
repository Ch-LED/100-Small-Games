# 05-asteroids — 策划案

## 定位

经典 Asteroids 复刻：一艘惯性飞行的三角飞船在**四面环绕**的场地里打碎小行星，大块裂成中块、中块裂成小块。不做玩法创新，把原作的「惯性 + 环绕 + 越打越碎越慌」这套手感做扎实。矢量图形由 `Polygon2D` / `Line2D` 绘制（无外部素材），音效全部程序化合成——沿用 02-space-invaders 的路线。

## 视觉与配色（全部矢量绘制，无外部素材）

- 场地：近黑的深蓝底 + 一层**静态星点**（纯装饰，不参与玩法）。
- 飞船：细长的三角轮廓（外描边 + 暗色填充），朝右为 0°，尾部喷口在推进时亮起**橙色火焰**。
- 小行星：不规则的**多边形轮廓**——每块按随机顶点数与随机半径抖动生成，所以没有两块长得一样；每块**自转**（快慢与方向随机）。
- 飞碟：扁圆盘轮廓，横向穿越场地上半区。
- 子弹：短小的亮点拖尾。
- 爆裂：几段短线向四周飞散并淡出。

## 音效（程序化合成，无外部素材）

启动时用代码合成 PCM 到 `AudioStreamWAV`，播放走 `AudioStreamPlayer` 池：

- **开火**：方波快速下滑，短促。
- **推进**：低频噪声循环，按住推进键期间持续播放。
- **碎裂**：白噪声爆响，大/中/小三档音高与时长递减。
- **飞船被毁**：更长更低的噪声爆响。
- **飞碟**：存活期间播放两音交替的颤音。
- **心跳**：经典的两音低频节拍，**场上小行星越少，节拍越快**——这是原作的紧张感来源。
- **加命**：上行小动机。

## 核心体验

- **四面环绕**：飞船、小行星、子弹出了边界都从对面回来，没有真正的"边"。
- **惯性飞行**：`A`/`D`（或 ←/→）**原地旋转**，`W`（或 ↑）**推进**，松开后凭惯性滑行（带轻微阻尼，见技术规格书 §5）；速度有上限。
- **开火**：空格发射子弹，同时最多 `max_bullets` 发在场。
- **碎裂链**：大块 → 2 中块 → 2 小块 → 消失；越碎越快、越碎分越高（20 / 50 / 100）。
- **飞碟**：每隔一段时间从一侧横穿，会朝飞船方向开火，可被击毁（200 分），撞上则两败俱伤。
- **波次**：清光所有小行星即过关，下一波块数更多、整体更快（有上限）。
- **生命**：初始 3 条，额外每 `10000` 分加一条。被撞掉一条命后原地重生，带一段无敌时间；**若重生点附近仍不安全，则延后重生**。
- **结束**：生命耗尽 → 结算，空格重开。

## 界面

- 顶部：`SCORE`、`HIGH`、`WAVE`，以及残机（用与飞船同款的小三角图标表示）。
- 中央覆盖文字：`PRESS SPACE TO START`、`GAME OVER / PRESS SPACE`、`WAVE N`。

## 作弊键与调试键

- **`C`（`cheat_toggle`）**：开关**无敌**——飞船不会被小行星、飞碟或其子弹击毁（仍然会开火、仍会过关）。视觉上飞船轮廓转为亮绿色，明确"现在撞不死"。
- **`P`（`debug_toggle`）**：只读可视化——给每个实体画出**碰撞圆**，并给每块小行星画出**速度矢量箭头**，便于核对"看起来碰上了"和"真的碰上了"。不改变任何玩法。

## 验收标准

- [ ] 从 hub 进入即见星点场 + 中央三角飞船，按空格开始。
- [ ] `A`/`D` 就地旋转，`W` 推进并有橙色火焰；松手后惯性滑行且最终停下；速度有上限。
- [ ] 四面环绕：飞船、小行星、子弹都从对面回来。
- [ ] 空格开火，同时在场子弹不超过 `max_bullets`。
- [ ] 打碎大块 → 裂成两块中块；中块 → 两块小块；小块 → 消失；分数 20/50/100 正确。
- [ ] 场上小行星变少时，心跳节拍明显加快。
- [ ] 飞碟定期出现、会开火、可被击毁（200 分），撞上飞船时双双消失。
- [ ] 清光即过关，第二波块数更多、移动更快。
- [ ] 三条命；被撞后有片刻无敌且闪烁；复活点不安全时会延后重生；10000 分加一条命。
- [ ] 命耗尽 → 结算画面 + 空格重开；`Esc` 返回 hub。
- [ ] 按 `C` 开启无敌后飞船变绿且撞不死；按 `P` 显示碰撞圆与速度矢量，且不改变玩法。
- [ ] 无素材导入报错；所有调参走 `asteroids.cfg`，代码零魔法数。

## 范围与非目标

- 不做：**超空间跳跃**（边界环绕已提供位移手段）、大小飞碟分级、双人、关卡特殊编队、排行榜持久化。
- 不引入外部美术/音频素材；不做粒子系统（爆散用矢量线段即可）。
- 最高分只在本次运行内累积。
