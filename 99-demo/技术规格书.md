# 99-demo — 技术规格书

> 模板：任何新游戏先复制本目录结构与这两份文档，再改写。

## 目录契约（复制即生效）

```
99-demo/
├─ 策划案.md  技术规格书.md     # 设计依据
├─ demo.tscn                    # 主场景：与目录名一致(去编号)= demo
├─ meta.json                    # { "name": 中文名, "icon": 图标路径 }
├─ assets/icon.svg              # 桌面图标（meta 缺省路径）
└─ scripts/demo.gd              # 主场景脚本
```

## 返回协议

- 退出回 hub：调用 autoload `GameRouter.back_to_hub()`（或捕获 `ui_cancel`）。
- 禁止自行卸载/假设 hub 内部。

## 运行

主场景默认指向 hub；本游戏只从 hub 桌面进入。无独立构建。
