# 99-demo — 策划案

## 定位

**模板示范游戏**：不是正式玩法，用于验证 hub 全链路（扫描 → 图标/名字 → 进入 → 返回），并作为新游戏的**目录与文档骨架样板**。验收后可删除或继续作模板留存。

## 玩法

无。点「返回桌面」或按 Esc 回到 hub，验证返回协议。

## 验收

- [ ] 在 hub 桌面出现「演示 Demo」图标与名字。
- [ ] 点击进入纯色画面；按钮/Esc 均能返回桌面且位置保持。
