# 12-tetris — 策划案

## 定位

**俄罗斯方块——按 Tetris Guideline 实现的版本。**

七种方块从顶部落下，玩家左右移动、旋转、加速下落，把它们码成整行消除。行消得越多、一次消得越多，分越高；方块堆到顶就结束。

这是全库**第一款"照外部规范实现"的作品**。前 11 款的规则都是本项目自己定的，这一款的每一条规则——随机方式、旋转系统、锁定行为、计分表——**都来自一份公开标准**，不是我们的发明。因此本作的技术规格书多了一节「标准依据」，把「哪些是规范规定的、哪些是我们自己定的」逐条划开。

## 标准依据

采用 **Tetris Guideline**——The Tetris Company 为授权游戏制定的一致性规范，本世纪以来稳定，各平台官方版本据此互通。

| 条款 | 本作采用的内容 |
| --- | --- |
| **7-bag 随机** | 七种方块洗成一袋依次发出，发完再洗。**不是纯随机** |
| **SRS**（Super Rotation System） | 方块四个朝向 + **踢墙表**（旋转受阻时按固定顺序尝试 5 组偏移） |
| **Hold** | 暂存当前方块，每块限一次 |
| **Ghost piece** | 落点投影 |
| **锁定延迟** | 落地后 0.5 s 才锁死；移动/旋转可重置，**上限 15 次** |
| **重力表** | 「等级 → 每格下落秒数」的查表曲线 |
| **计分表** | 单 / 双 / 三 / Tetris、T-spin、combo、back-to-back |
| **标准配色** | 七种方块的颜色（见下） |

⚠️ **数值照规范写，但未能逐字核对原文**：这台机器上 `WebFetch` 被网络策略整个挡住（详见 `DECISION_LOG` 086 的记载），规范正文拿不到。所以表里的数字来自既有知识，**由断言套件与实机两轮校验**。若与权威版本有出入，以规范为准修代码。

**规范没有规定、属于本作自定的**（全部进 `.cfg`，必须实机调）：

- **DAS / ARR**——长按横移的起始延迟与重复速率。规范对此**完全留白**，每个实现都不一样。
- 音效、界面排版、三个全局键的行为。

## 三条模式

| 模式 | 结束条件 | 记录 |
| --- | --- | --- |
| **马拉松**（无尽） | 方块堆到顶 | 最高分 |
| **冲刺** | 消满 **40 行** | 最短用时 |
| **教程** | 五关过完 | 不记 |

前两条的**规则完全相同**，只有结束条件与计分口径不同（冲刺不看分数，只看时间）。冲刺是标准竞速项目，比的就是手速与堆叠效率。

**教程**是一条独立的线：五关，每关**一个手摆的开局 + 一个目标 + 一句讲解**，从"消一行"一路教到 **Tetris / T-spin / Hold / Combo**。它复用**完全相同的规则**，只是开局固定——所以在这里学会的东西拿到真局里照样成立。详见 `技术规格书.md` §16。

**为什么需要它**：这款游戏里有几样东西**只看画面是学不会的**——Tetris 值单行的 8 倍、贴着自己转进去能拿 800 分、连着消有额外加成。计分表能写进文档，但写不进手感。教程就是把这些局面手工摆到玩家面前，一次只教一件。

## 视觉与配色

- **深底 + 亮格子**：棋盘压在深蓝紫底上，方块用高饱和色点亮。像素风，方块边长 32 px，每块带**内描边 + 左上高光**——纯色块看不出"这是一块砖"，加一道高光才有体积。
- **七种方块用 Guideline 标准色**，一色一块，全程不换：

  | 方块 | 颜色 | hex |
  | --- | --- | --- |
  | I | 青 | `#00F0F0` |
  | O | 黄 | `#F0F000` |
  | T | 紫 | `#A000F0` |
  | S | 绿 | `#00F000` |
  | Z | 红 | `#F00000` |
  | J | 蓝 | `#0000F0` |
  | L | 橙 | `#F0A000` |

- **Ghost（落点投影）**是**同色的空心描边格**，不加高光——实心会跟真方块分不清，纯灰又会丢掉"这是哪个方块"。
- **消行前有一下闪白**，然后整行塌下去。这一下闪是玩家唯一能确认"我确实消到了"的反馈，不能省。
- 字体用项目统一像素字体 `Press Start 2P`（`plugins/pixel_font`）。
- **超级作弊的绿色 `#00E676`** 与项目约定一致（详见「键位」）。

## 音效（程序化合成，无外部素材）

- **移动**：极短的木质"嗒"。
- **旋转**：比移动高一点的"咔"。
- **锁定**：落地的闷响，低而短。
- **消行**：上行音阶，**一次消得越多音越高**——消一行一个音，Tetris（四行）是四音上行，这一串音就是玩家的收获读数。
- **T-spin**：独立的琶音，**与消行音区分开**。这是"我刚才那下是技巧"的唯一听觉确认。
- **升级**：上行三音。
- **顶死**：下行长滑音。
- **破纪录**：比结算再高一层的一段音。

## 核心体验

- **操作**：
  - **左右**：`←` / `→`（或 `A` / `D`）横移，**按住连发**（DAS/ARR）。
  - **软降**：`↓`（或 `S`）加速下落，每格 +1 分。
  - **硬降**：`空格`**直落到底并立刻锁定**，每格 +2 分。
  - **顺时针旋转**：`X`（或 `↑` / `W`）。
  - **逆时针旋转**：`Z`。
  - **暂存**：`C`，把当前方块存起来，换出上一个存过的；**每块只能存一次**，落地后才解锁。
  - **`Esc`**：暂停菜单。
- **玩家的心智模型**（这五条是标准俄罗斯方块的全部技巧来源）：
  - **方块不是纯随机来的**——七种一袋，所以"接下来会来什么"是可以推的；
  - **贴着墙和缝也能转**——踢墙表让方块在受阻时自动蹭开一点，**这是 T-spin 的物理基础**；
  - **落地不等于锁死**——有 0.5 s 可以再挪一下，但**挪不了无限次**；
  - **一次消四行最值钱**——Tetris 的分数是单行的 8 倍，不是 4 倍；
  - **连续有收获会加成**——连着消（combo）和连着做高难度动作（back-to-back）都额外给分。
- **难度**：等级由累计消行数驱动（每 10 行一级），等级进重力表查到下落间隔。等级越高落得越快，**玩家能思考的时间越来越短**——这就是这款游戏的全部难度曲线。
- **失败**：新方块出生位置被占住（顶死）→ 结算。
- **目标**：马拉松打尽可能高的分；冲刺用尽可能短的时间消满 40 行。

## 界面

- **主菜单**：标题、`MARATHON` / `SPRINT` 模式选择、`BACK`。每个模式下面挂着它的历史记录（最高分 / 最快用时）。
- **游戏中 HUD**：
  - **棋盘右侧**：Hold 槽（上）、Next 队列（下，**看得到接下来 5 个**）。这两样是玩家规划的依据，**必须与棋盘同屏且不遮挡**。
  - **棋盘上方或侧栏顶部**：分数、等级、消行数。冲刺模式下换成**计时**与 `n / 40`。
- **暂停菜单**（`Esc`）：`RESUME` / `RESTART` / `QUIT TO MENU`。
- **结算**：显示本局成绩与历史最佳；破纪录时那行改成 `NEW RECORD`。**`空格` 再来一局，`Esc` 回主菜单**，两条都写在卡上。

## 键位

三个全局键按项目约定接上：

- **`Q` 落点投影（Ghost）**：当前方块直落到底的那四格，用同色的空心框标出。**默认显示**，按 `Q` 关掉。
- **`P`（`debug_toggle`）只读叠加**：棋盘的**格子网格**、**可见区顶部的生成线**、**活动方块的包围盒与中心十字**（**T-spin 判定的依据就是这四个角**）、逐格描边，以及四行读数（方块与朝向 / 当前重力 / 锁定剩余与重置次数 / 7-bag 还剩哪几块）。纯诊断，不改变任何玩法。
  - **和 `Q` 分开是因为它们服务于不同的时刻**：`Q` 是玩的时候看的（我这一下会落在哪），`P` 是想"为什么"的时候看的。
- **`[`（`cheat_toggle`）时间膨胀**：重力间隔与锁定延迟**各乘 3**——落得慢、来得及想、来得及挪。HUD 的等级旁标一个 `SLOW`。与 `07-breakout` 的"加宽挡板"同型：都是给玩家更大的容错，只是这款的容错单位是**时间**。
- **`]`（`super_cheat_toggle`）零重力**：方块**不再自行下坠**——重力整个关掉，它停在玩家放手的那个位置，放多久由玩家定。左右移动、旋转、软降（`↓`）、硬降（空格）**全部照常**，**只有"时间"这一维被拆掉了**。方块**变荧光绿 `#00E676`**（整块变绿，因为被接管的就是它）。
  - **为什么是零重力而不是"机器替你玩"**：重力是俄罗斯方块**最根本的约束**——整个游戏就是与下落赛跑。拆掉它比替你玩有趣得多（可以慢慢摆出任何造型），而且**顺手把调试也变简单了**（能把方块停在任意位置验证消行与 T-spin）。**自动化只属于"想不出别的花样"的游戏**（解谜 / 音游），本作不是——这条已写进 `CONSTITUTION.md` 八。
- 三者**彼此独立**；`[` 与 `]` 在**每局开始 / 重开时复位**。

## 验收标准

- [ ] 从 hub 进入后看到**主菜单**；选模式进游戏，`Esc` 回 hub。
- [ ] 方块从顶部落下，**`←` / `→` 横移（按住连发）**、**`↓` 软降**、**`空格` 硬降并立即锁定**。
- [ ] **`X` 顺时针 / `Z` 逆时针**旋转；方块**贴着墙或贴着别的方块也能转**（踢墙生效）。
- [ ] **`C` 暂存**：当前方块换下去、上一块换上来；**同一块只能存一次**。
- [ ] **落点投影（Ghost）**默认显示——方块正下方的一圈空心框，随方块移动实时更新；按 `Q` 关掉，再按一次打开。
- [ ] 落地后有**约半秒**可以再挪动/旋转；**挪够 15 次后强制锁死**。
- [ ] 码满一整行**闪白后消除**，上方整体下落。
- [ ] **消行、T-spin、combo、back-to-back 的加分与规范一致**（逐条对照规格书 §6 的计分表）。
- [ ] 等级随消行上升，**下落速度按重力表加快**；等级读数与速度对得上。
- [ ] 方块堆到顶 → 结算显示本局分数；**马拉松的最高分写进存档**，退出重进还在。
- [ ] **冲刺模式消满 40 行即结束**，结算显示用时；**最快用时写进存档**。
- [ ] 存档文件**不存在 / 损坏 / 版本不符**时游戏照常启动（回退空存档），**后两种在菜单上明说**，不把 0 分当成真有人打过。
- [ ] `Esc` 分层正确：主菜单→hub、游戏中→暂停菜单、结算→主菜单。
- [ ] `P` 出现只读叠加；再按一次立即消失。
- [ ] `[` 后下落明显变慢，HUD 标 `SLOW`；开新局复位。
- [ ] `]` 后方块**停在空中不再自行下落**，用 `↓` / 空格仍能自己把它送下去，方块变绿；开新局复位。
- [ ] **7-bag 生效**：连续观察多袋，**七种方块各出现一次才重复**。
- [ ] 无素材导入报错；所有可调参数走 `tetris.cfg`，代码零魔法数。

## 范围与非目标

- **只做单人**。不做对战、不做垃圾行（garbage）、不做攻击系统。
- **只做规范里那套计分**：T-spin 与 combo / back-to-back 做全，但**不做**规范之外的连击扩展（如 Perfect Clear 的额外奖励、连续 T-spin 的倍率爬升）。
- **两条模式就够**：不做限时（Ultra）、不做闪电压缩（Blitz）、不做练习模式。
- **不做自定义键位界面**。键位是项目级约定（见「键位」与 `CONSTITUTION`），改键改配置文件。
- **不做手柄 / 触屏**。项目至今全是键盘，这一款不破例。
- **不追求"复刻某一个具体版本"**。依据是规范条款，不是某一台的 ROM 行为——规范没规定的部分（DAS/ARR、音效、排版）按本作自己的判断做。
