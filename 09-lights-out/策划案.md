# 09-lights-out — 策划案

## 定位

经典 Lights Out 复刻：5×5 的灯阵，点一盏会**连带翻转它自己和上下左右四盏**，目标是把所有灯全灭。谜题由"从全灭出发随机按若干次"生成，因此**保证有解**。图形全部由 `Panel` + `StyleBoxFlat`（圆角）构成，**无外部素材**；音效全部程序化合成。

## 视觉与配色（全部代码生成，无外部素材）

- 深底 + 一块棋盘底板，5×5 的圆角方块**要么暗要么亮**（亮是暖黄，暗是低饱和蓝灰），一眼能数清还有几盏亮着。
- **光标**（键盘操作时）用亮白描边标出当前位置；**解提示**（作弊键）用亮青描边。
- 25 个格子是**场景里的固定结构**，由 `GridContainer` 排布——位置不用代码算。

## 音效（程序化合成，无外部素材）

- **按下**：短方波，**音高按所在行**（越靠下的行音越高），连点有音阶感。
- **过关**：上行小动机。
- **新题**：一声柔和起音。

## 核心体验

- **操作**：
  - **鼠标**：直接点某一盏灯。
  - **键盘**：方向键 / WASD 移动**光标**，**空格点亮/熄灭火光标所在的那盏**。
  - 一旦动了鼠标，光标自动隐藏（避免和鼠标打架）。
- **翻转规则**（原作契约）：按下 (r,c) 会翻转 **(r,c) 与上下左右四邻**，越界的邻居不存在就忽略。
- **目标**：全部熄灭。
- **保证有解**：谜题不是随机洒的，而是**从全灭状态随机按 N 次**得到的——因为"按一次"就是自己的逆操作，所以这样生成的局面必定可解。
  - 附注：标准的 5×5 Lights Out **并不是每个局面都有解**（系数矩阵秩为 23、零空间有 4 个元素，所以是 4 个"静默图案"），**随手洒一盘有相当概率是死局**——这才是"从全灭出发倒推"这个生成方式的意义所在。
  - 另一面：同一局因此通常有 **4 组解**（各组相差一个静默图案，**步数不一样**）。作弊键给的是其中**最短**的那组。
- **关卡**：过关后自动进入下一题，**生成时按的次数逐关增加**（有上限），越往后越费脑。
- **计步**：累计你按了多少次；过关时显示 `SOLVED IN n`。
- **没有"换一题"**：既然每题都可解，就没有卡死的可能；想重来可以 `Esc` 回 hub 再进（会重新生成）。
- **没有结束**：这是谜题，不是消耗类游戏；`SOLVED` 累计本次运行解出了几题。

## 界面

- 顶部：`LEVEL`、`PRESSES`（本题按了多少次）、`SOLVED`（本次运行解出几题）。
- 棋盘上方一行读数（`P` 打开时）：`PRESSES n`、`LIT m`、`OPTIMAL k`。
- 棋盘下方：`PRESS SPACE TO START`、`SOLVED IN n`、`LEVEL n` 等提示。

## 作弊键与调试键

- **`[`（`cheat_toggle`）SOLUTION**：**把最优解算出来并用亮青描边标在需要按的格子上**。用追灯法（枚举第一行的 32 种按法，再逐行往下"追"）求出来，是这道题最实在的作弊——不只告诉你答案，还顺便说明了这类谜题是怎么解的。
- **`P`（`debug_toggle`）**：只读读数——`PRESSES`（按了几次）、`LIT`（还亮着几盏）、`OPTIMAL`（**最少几步能解**）。**不标出位置**，所以它只是诊断，不会剧透答案。
- **`]`（`super_cheat_toggle`）**：**游戏自己解**。开着它就不用动手了——每隔 `auto_press_period`（0.7s）替你按下最快解法的**下一步**，一路按到全灭。按下去走的是和鼠标/键盘**同一扇门**，所以灯光、计数、音效与你亲手按的一模一样。
  - **它把"下一步"那一格描绿**（超级作弊的统一色），而且**只标这一格**——重点是让你看见机器此刻在做什么，不是把答案摊开。
  - **重置**：回标题与开新局都会关掉；过关不会（作弊按"局"复位，与其它游戏一致）。

## 验收标准

- [ ] 从 hub 进入即见 5×5 灯阵（开局全灭），按空格开始并生成一题。
- [ ] 按 `]`（`super_cheat_toggle`）后**什么都不做**，游戏自己按最优解把这一题解掉（每次约 0.7s 一步，**下一步那一格描绿**，且同一时刻只描一格）；再按一次停下；**开新局自动关**。
- [ ] 鼠标点灯即翻转；键盘方向键/WASD 移动光标、空格翻光标所在的灯。
- [ ] 翻转严格是"自己 + 上下左右"，边界外忽略；同一格连点两次回到原状。
- [ ] 生成的每一题都真的可解（断言：用求解器解它，必然解得出且解完全灭）。
- [ ] 全灭 → 提示 `SOLVED IN n` → 自动进入下一题，且下一题的生成按次更多。
- [ ] 按 `[` 后用亮青描边标出需要按的格子，且**这些格子按完确实全灭**；再按一次收起。
- [ ] 按 `P` 显示读数，`OPTIMAL` 与实际最少步数一致，且**关掉后立即消失**。
- [ ] `Esc` 返回 hub；无素材导入报错；所有调参走 `lights-out.cfg`，代码零魔法数。

## 范围与非目标

- 不做：非 5×5 棋盘（3×3 / 4×4 / 7×7 变体）、限步模式、计时模式、关卡编辑器、最高分持久化。
- 不做"换一题"按钮（见上）。
- 不引入任何外部美术/音频素材。
