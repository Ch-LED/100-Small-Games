# 15-minesweeper — 技术规格书

### 3.1 棋盘没有逐格节点

一格是"一块底色 + 一个字形 + 可能的标记"，两种状态（未翻开 / 已翻开）都由 `_draw` 直接画出。**16×30 的专家盘是 480 格**，也就是一次 `_draw` 里 480 次格子绘制——比 480 个节点便宜得多。

## 4. 数据模型（`minesweeper_board.gd`，`class_name MinesweeperBoard`）

**纯逻辑，`extends RefCounted`**——不碰场景树、不发信号。

- 四份等长的字节数组：`mines`、`revealed`、`flags`、`adjacent`。
- `Flag` 枚举：`NONE` / `MARK`（旗）/ `QUESTION`（问号），`toggle_flag` 按 3 循环。

### 4.1 ★ 雷在第一次点击之后才布下

`seed(rng, safe_cell)` **把 `safe_cell` 和它周围八格从候选里剔除**再随机放雷。这不是"先布雷再重布"，而是**根本不给首点周围放雷的机会**——首点安全是构造出来的，不是运气。

因此 `reveal()` 在 `seeded == false` 时只返回 0（保护），真正的布雷由 play 在首点前调用 `seed()`。**计时也从这一刻开始。**

### 4.2 连锁与旗

`_flood()` 用队列展开：翻到 0 就把邻格入队，**遇到旗就停**。旗是玩家在说"这边别走"，连锁尊重它。

### 4.3 和弦

`chord(cell)`：已翻开的**数字格**，若周围旗数 == 该数字，一次翻开其余邻格；翻开时若碰到雷，`exploded` 置位，返回 -1。**和弦和单击一样会输**——它不是安全的推理辅助。

### 4.3.1 `]` 的单步推理

`deducible_mines()` 扫一遍已翻开的数字格：某个数字周围**未插旗且未翻开**的格子数，若正好等于"该数字 − 周围旗数"，这些格子全部标为雷。

**只做一步，不交底**——它替玩家做完那一步算术，安全格在哪、下一步开哪仍要自己判断。这也让它和"所有雷直接显示"有了本质区别：后者把游戏变成抄答案。

### 4.4 胜负

- **输**：`exploded >= 0`。
- **赢**：`is_won()` 写成"**没有一颗安全的格子还没翻开**"，而不是"翻开数 == 总数 − 雷数"。
  - ⚠️ 后者在 `[` 作弊下会失效：作弊让雷也能被翻开，翻开数会**超过**目标值，于是永远赢不了。判据改成"扫一遍安全格"就与作弊无关了。

**旗插错不影响胜负**——旗是玩家的笔记。

## 5. 对局（`minesweeper_play.gd`，`class_name MinesweeperPlay`）

- **首点**：未布雷 → `seed(rng, cell)` → 开始计时 → `reveal(cell)`。
- **已翻开的格子用左键** = 和弦。
- **`[` 作弊**：`reveal` 返回 -1 时，play 把 `exploded` 清掉、手动把该格标为已翻开。**那一格照常显示成雷**，所以它还教东西。
- **结束延迟 0.8 秒**再发 `finished(won, elapsed_ms)`：结束的盘值得看一眼。
- **鼠标**：`_input` 拿左键 / 右键 / 移动；`_cell_at()` 用 `get_global_transform().affine_inverse()`（`Control` 没有 `to_local`）。
- **键盘**：方向键移光标、空格翻开、`Z` 插旗。鼠标悬停也会把光标移过去，两套操作共用一个光标。

## 6. 配置 `minesweeper.cfg`

| 分区 | 关键项 | 职责 |
| --- | --- | --- |
| `[board]` | 底 / 未翻开 / 亮边 / 地板 / 网格 / 八种数字色 / 旗 / 雷 / 错旗 / 作弊绿 / 光标 / 三种文本色、`cell_size`、`edge_scale` | 棋盘外观 |
| `[levels]` | `names` / `rows` / `cols` / `mines` | 三档难度（9×9/10、16×16/40、16×30/99） |
| `[audio]` | 五个基频 + 两组音阶 | 各事件音高 |
| `[hud]` | `font_size` `margin` | HUD |

- ⚠️ **`MinesweeperSettings` 每个键都有兜底值**，加键时两处一起改。
- `cell_size = 28` 让专家盘（30 列 × 28 = 840）在 1280 宽里放得下，16 行 × 28 = 448 在 720 高里留得出 HUD 的位置。

## 7. 只读叠加层（`minesweeper_debug.gd`）

- **`P`**：难度与尺寸、雷数、旗数、已开格数、是否已布雷、是否结束、两个作弊开关、光标坐标、**光标格是不是雷 / 周围几颗雷**、本档最佳。
- **它只读**：一格都不翻。
- 带 setter 的开关写法（DECISION_LOG 029）；读数用亮品红 `FF3FA4`，方便像素计数验证。

## 8. 程序化音频（`minesweeper_audio.gd`）

启动时合成到 `AudioStreamWAV`（22.05 kHz / 16-bit / 单声道），6 个声部轮转。

| 事件 | 音色 |
| --- | --- |
| 翻开 / 和弦 | 短音 |
| 插旗 / 撤旗 | 中音 / 低一点 |
| 爆炸 | **下行滑音** |
| 通关 | 上行四音 |
| 破纪录 | 上行三音 |

- ⚠️ `_render` 用相位积分，不用 `sin(2π·f(t)·t)`（f 变化时会跳音）。

## 9. 输入

**本作没有往 `project.godot` 加新键**——复用 `arrow_*` / `wasd_*` / `fire` / `key_z`。

| 语义 | 来自 |
| --- | --- |
| `mines_left/right/up/down` | `arrow_*` / `wasd_*` |
| `mines_open` | `fire`（空格） |
| `mines_flag` | `key_z` |

约定动作（`P` / `[` / `]` / `Esc`）全项目固定，直接读。**`key_z` 在这里是"插旗"**——同一键在不同游戏不同义是设计（CONSTITUTION 七）。

## 10. 风险 / TODO

| 事项 | 优先级 | 说明 |
| --- | --- | --- |
| 不保证"无猜解" | 中 | 有些局面只能靠猜。**保证无猜需要求解器**，且会大幅改变出题与难度曲线；当前以"首点安全"作为唯一的公平性保证。 |
| 和弦没有视觉提示 | 低 | 玩家得知道"点已翻开的数字会连锁"这件事。实测能不能自己发现，要问。 |
| 无撤销 | 低 | 扫雷没有撤销是传统；误点即输。 |
| 专家盘 480 格每帧重绘 | 低 | 只在鼠标移动/操作时重绘，实测无感。 |

## 11. 验收

### 可自动校验的（headless）

```bash
godot --headless --path . --import
godot --headless --path . --script res://15-minesweeper/scripts/minesweeper_check.gd
godot --headless --path . res://15-minesweeper/minesweeper.tscn --quit-after 120
```

- 断言套件（`minesweeper_check.gd`，**65 项**）：
  - **布雷**：雷数正确；**首点及其八邻无雷**（中心与角落各验一次）；**盘太小放不下时拒绝而不是少放**；每格的数字等于周围雷数。
  - **翻开**：带数字的格只开自己；0 格连锁到贴边；连锁停在雷前；踩雷返回 -1 并结束；结束后不再接受翻开。
  - **标记**：三态循环、计数只算旗、已翻开的格拒绝标记、旗挡住翻开。
  - **和弦**：旗数不足什么都不做；旗数正确翻开其余；**旗数正确但推错会输**（和单击一样）。
  - **胜负**：开完所有安全格即胜；胜局不是败局。
  - **配置**：三档、每档留得出首点的空间、每档放得进场地。
- **冒烟（一次性脚本，已跑完删除）**：实例化真实 `play.tscn` 并驱动——**五次不同的首点没有一次踩雷**、首点一定翻开东西并启动计时、插旗三态循环与剩余雷数、`[` 作弊下踩雷不结束且该格照常翻开、`]` 不改任何格子、开完安全格获胜、踩雷即败。**37 项全过。**

### 已跑过的

- `--import`：零 error / warning。
- 断言 65 项通过 / 0 失败；冒烟 37 项通过 / 0 失败。
- 场景 headless 加载无脚本错误。

### 只有人能定的

- 观感：凸起格子的亮边够不够"砖感"、八种数字色的辨识度、28px 格子在小盘上会不会太空。
- 手感：右键三态循环是否顺手（还是只要两态）、和弦用左键点已翻开格是否会被误触发。
- 听感：爆炸的下行滑音、开格的短音。
- 难度：三档经典参数是否合适，尤其专家盘的 480 格在 28px 下读不读得清。
