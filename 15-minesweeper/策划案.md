# 15-minesweeper — 策划案

## 定位

经典扫雷。左键翻开、右键标记，数字是周围八格的雷数，翻开所有安全格即胜。三档经典难度：9×9/10 雷、16×16/40 雷、16×30/99 雷。

**雷在第一次点击之后才布下**，而且**首点连同它周围八格都保证没有雷**。所以第一下既不会炸，也一定翻开一片——这是本作唯一一条与"经典 Windows 扫雷"不同的口味调整，它把"开局就靠运气"这件事整个拿掉了。

图形全部由 `Control._draw()` 绘制，**无外部素材**；音效全部程序化合成。

## 视觉与配色（全部代码生成，无外部素材）

- **未翻开的格子是亮色凸起**：深色底上一块浅蓝灰，左上打一道亮边，读起来像一块砖而不是一个洞。
- **翻开之后露出地板**：更深的底色，数字按经典配色（1 蓝、2 绿、3 红、4 紫、5 琥珀、6 青、7 橙、8 白）。
- **旗是红色小三角**，问号是灰色 `?`。
- **踩中的雷**：整格染红，雷画成白圆。
- 游戏结束时**全盘亮出**：没被找到的雷显示成白圆，**插错的旗变灰**。

## 音效（程序化合成，无外部素材）

翻开（短音）、插旗（中音）、撤旗（低一点）、爆炸（下行滑音）、通关（上行四音）、破纪录（上行三音）。

## 核心体验

- **左键**：翻开；点到**已翻开的数字格**时是**和弦**——如果它周围的旗数已经等于这个数字，一次翻开其余邻格。
- **右键**：标记循环：空 → 旗 → 问号 → 空。已翻开的格子不接受标记。
- **脚印**：翻到 0 会**连锁展开**整片相邻区域；旗会挡住连锁（旗是玩家在说"这边别走"）。
- **输**：翻到雷。
- **赢**：所有安全格都翻开。**旗插错不影响胜负**——旗是玩家的笔记，不是游戏账本。
- **计时**：从**第一次点击**开始。

## 界面

四屏，整屏替换（与 10–14 同构）：

- **主菜单**：三档难度，每档下面写着尺寸、雷数与最佳成绩。
- **对局**：顶栏 `难度 / 时间 / MINES 剩余`；中央棋盘；底部只有一行 `ESC MENU`。
- **暂停**（`Esc`）：`RESUME` / `NEW BOARD` / `QUIT TO MENU`。
- **结算**：`CLEARED` 或 `BOOM`，用时，最佳（破纪录时绿色 `NEW BEST`）。

## 作弊键与调试键

**不在屏幕上写任何按键提示**——作弊是留给人自己发现的（DECISION_LOG 100）。

- **`P`（`debug_toggle`）**：只读叠加层，画在棋盘左侧的空白带里——难度与尺寸、雷数、旗数、已开格数、是否已布雷、是否结束、两个作弊开关、光标坐标、**光标格是不是雷 / 周围几颗雷**、本档最佳。**它只是读数，一格都不翻。**
- **`[`（`cheat_toggle`）**：**踩雷不炸**。翻到雷的格子照常翻开并显示成雷，但这一局继续。最直白的"把这一局变简单"。
- **`]`（`super_cheat_toggle`）**：**所有雷直接显示出来**（绿色 `#00E676`）。拆掉的是扫雷赖以为生的那条约束——"你只能推理，不能直接看见"。

## 验收标准

- [ ] 从 hub 进入即见主菜单，三档难度各显示尺寸、雷数与最佳；`Esc` 回 hub。
- [ ] **连续多次开局，第一次点击从不踩雷**，且首点周围八格也没有雷。
- [ ] 首点翻开一片（至少一格），计时从这一刻开始。
- [ ] 左键翻开；翻到 0 连锁展开；旗会挡住连锁。
- [ ] 右键标记循环：空 → 旗 → 问号 → 空；已翻开的格子不接受标记。
- [ ] 点已翻开的数字格，**旗数匹配时和弦翻开其余邻格**；旗数不匹配时什么都不发生。
- [ ] 翻到雷即输，全盘亮出：未找到的雷显示、踩中的那颗染红、插错的旗变灰。
- [ ] 所有安全格翻开即胜（**旗插错也算赢**）。
- [ ] 按 `[` 后踩雷不炸、那一格照常翻开并显示成雷，再按还原；**开局复位为关**。
- [ ] 按 `]` 后所有雷以绿色显示，再按还原；**开局复位为关**。
- [ ] 按 `P` 显示读数、再按消失，且**读数一格都不改**。
- [ ] 键盘能玩：方向键移光标、空格翻开、`Z` 插旗。
- [ ] `Esc` 打开暂停菜单且时间停止；三条路都对。
- [ ] 存档不存在 / 损坏 / 版本不符三种情况都能启动，菜单上明说 `SAVE UNREADABLE`。
- [ ] 无素材导入报错；所有调参走 `minesweeper.cfg`，代码零魔法数。

## 范围与非目标

- 不做：自定义尺寸 / 自定义雷数。
- 不做：三次点击内保证可无猜解（这一条需要求解器，且会显著改变出题）。
- 不做：排行榜、旗帜图案选择、触屏长按。
- 不引入任何外部美术/音频素材。
