# 00-hub — 技术规格书

> 依据：`00-hub/策划案.md`。设计决策见 `DECISION_LOG.md` 条目 005–008。本规格书与实现冲突时修正实现。

## 1. 运行模型与生命周期

- 引擎：Godot 4.7（Forward Plus）。`project.godot` 的 `run/main_scene` = `res://00-hub/hub.tscn`。
- **整树切换**：hub 与游戏之间用 `SceneTree.change_scene_to_file` 互切，每次切换销毁旧场景树。
- **autoload `GameRouter`**（脚本 `00-hub/scripts/game_router.gd`，autoload 名 `GameRouter`）：唯一的全局状态与跳转入口，hub 与所有游戏都只通过它进出。

### GameRouter 状态与接口

```
state:
  landing: String   # "title" | "grid" — hub 重建后落到哪个界面
  grid_scroll: float  # 桌面垂直滚动偏移，用于返回恢复
  grid_column_count: int  # 当前列数（可选，供恢复一致性）

api:
  enter_game(dir: String)   # dir = 完整游戏目录(含编号)，如 "99-demo"；记 landing="grid" 并保存当前滚动 → change 到 res://<dir>/<slug>.tscn
  back_to_hub()              # change 回 res://00-hub/hub.tscn（landing 决定落点）
  quit_app()                 # get_tree().quit()
```

### 场景树（00-hub/hub.tscn，根 Control 全屏）

```
Hub (Control, full rect)
├─ TitleScreen (CanvasLayer 内, 见 scenes/title_screen.tscn)   # landing=="title"
└─ GridScreen (CanvasLayer 内, 见 scenes/grid_screen.tscn)     # landing=="grid"
```

- hub.tscn 只做一件事：读 `GameRouter.landing`，显示对应一屏、隐藏另一屏；不重复扫描。
- 冷启动 `landing` 默认 `"title"`；从游戏返回前 Router 已置 `"grid"`，故回桌面而非标题。

## 2. 目录扫描与元数据（发现管线）

### 扫描规则（constants 集中，禁止散落魔法字符串）

- 顶层目录集合：`DirAccess.get_directories_at("res://")`。
- 保留匹配 `^\\d{2}-.+` 的目录；**排除 `00-` 前缀**（hub 自身）。
- 每目录 slug = 去掉 `NN-` 前缀的剩余部分（目录名即 slug）。
- 自然排序：按两位前缀字典序即 `01, 02, …`。
- 主场景路径：`res://<dir>/<slug>.tscn`，进入前用 `ResourceLoader.exists` 校验。

### 每游戏入口数据（`GameEntry`）

```
{ num: String, slug: String, scene_path: String,
  display_name: String, icon_path: String | "" }
```

| 情形 | 处理 |
| --- | --- |
| `meta.json` 存在 | `name` 作 display_name；`icon` 缺省 `assets/icon.svg` |
| `meta.json` 缺失/损坏 | 降级 display_name = slug；图标用占位 |
| 图标文件不存在/加载失败 | 该项渲染占位块（不中断整屏） |
| 目录缺主场景 `<slug>.tscn` | 该项**跳过**并在 push_warning 记录；其余照常 |
| 进入时场景加载失败 | 显示轻量错误提示，不退出 hub 树 |

- meta.json 仅含展示信息，不含玩法；`GAME_INDEX.md` 由人维护作总览，**运行时绝不解析 md**。

## 3. 界面结构与自适应

- 分辨率策略：`project.godot` 设 `window/stretch/mode=canvas_items`、`aspect=expand`（已有）+ base design `1280x720`；一切 UI 用容器与锚点，禁绝对坐标。
- **TitleScreen**：居中 VBox——logo(TextureRect) + 标题 Label + HBox(「开始」主按钮、全屏切换、退出)。全屏切换 = `DisplayServer.window_set_mode`，按钮文案在「全屏 / 窗口」间切换。
- **GridScreen**：`ScrollContainer`(铺满) > `VBoxContainer` > 每行一个 `HBoxContainer`/直接一个 `GridContainer`。采用 **GridContainer 固定列 + ScrollContainer 纵向**，列数按 `available_width / cell_width` 在 `resized` 时重算（`GridContainer.columns` 需在每行重排，或用一个自排行的 VBox 网格）。实现取用 GridContainer，列数变化时重建行——首版可用较简实现，复杂排版进 TODO。
- **AppCell**（`scenes/app_cell.tscn`，数据驱动复用）：`Button`(icon, 方形、圆角 ThemeOverride) + 下方 `Label`(display_name，自动换行/截断)。点击 → `GameRouter.enter_game(entry.slug)`。
- 顶栏：桌面顶部一条窄栏：返回标题按钮 + 计数「N 款游戏」+（可选）刷新。

## 4. 模块划分（脚本清单，均在 00-hub/scripts）

| 文件 | 职责 |
| --- | --- |
| `game_router.gd` | autoload；进出/quit/状态恢复（见 §1） |
| `game_discovery.gd` | 纯函数扫描：目录 → 排序 → 校验 → 读 meta → `GameEntry[]` |
| `hub_root.gd` | hub.tscn 根：按 landing 切屏 |
| `title_screen.gd` | 开始/全屏/退出按钮 |
| `grid_screen.gd` | 拿 discovery 结果建 AppCell 网格、维护滚动恢复 |
| `app_cell.gd` | 单格渲染 + 点击回调（signal） |

无 GDScript 静态依赖 hub 之外；**代码中不得出现中文**（注释/命名全英文）。

## 5. 容错与边界

- 损坏条目逐项降级，绝不让一个坏目录崩掉整棵树。
- enter_game 对 `NN-` 与 slug 拼接做一次存在性断言；失败提示后回 grid（复用 `landing`）。
- 启动即扫描最多 ~100 项，首版同步加载可接受；资源体积上来后再做懒加载。

## 6. TODO / 重构预留（首版不实现，标明优先级）

| TODO | 优先级 | 潜在问题 | 预计重构时机 |
| --- | --- | --- | --- |
| 图标懒加载 + 异步纹理回调 | 中 | 100+ 大图标同步 load 拖慢进入桌面 | 图标普遍超 256px 后 |
| Grid 虚拟化 / 更精细排版 | 低 | 项数上限 99，尚未成瓶颈 | 项数或图标变多变重后 |
| 场景入场/退出过渡动画 | 低 | 纯观感，不影响功能 | 打磨润色专项活动 |
| 网络/自定义主题 | 低 | 明确非目标 | 视演进需求 |

## 7. 测试路径

- `godot --path .`（或编辑器 F5）：标题 → 开始 → 桌面见 `99-demo` → 点入 demo → 返回桌面位置保持；任意改窗尺寸/全屏不裁切；往返多次无叠积。
- 容错测试：临时给某目录删 meta/场景，确认桌面仅降级该项。
- 静态：无自动化测试框架，靠上述手测 + `--headless --import` 校验资源。
