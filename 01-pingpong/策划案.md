# 01-pingpong — 策划案

## 定位

首款正式小游戏（也是后续 99 款的结构样板）。单人对战乒乓：右侧红拍属玩家，左侧蓝拍属电脑；无素材、无音效，图形全部由 `ColorRect` 纯色块构成，物理全部由 `Area2D` 承载。

## 视觉与配色（全部代码生成，无外部素材）

- 场地背景：纯淡灰。
- 中缝：屏幕中央垂直白色**半透明粗实线**，划分左右半场。
- 球拍：左右各一矩形色块——左蓝（电脑）、右红（玩家）。
- 乒乓球：浅橙红色小球。

## 核心体验

- **操作**：W/S 或 ↑/↓ 控制红拍上下；两组键各自独立，fallthrough 为同一向上/向下意图。
- **电脑**：简单规则追球——采样小球 y 与拍心 y 的距离差生成移动命令，命令有 0.08–0.12s 操作冻结（反应参数可配置，可关闭），形成"每约 0.1s 想一次"的追球感。
- **弧面手感**：拍虽视觉为矩形，反弹法线随接触点偏离拍心的距离轻微旋转，并叠加小角度随机，使回球角度变化。
- **计分**：屏幕正中央一枚巨大**半透明**数字，代表玩家净分。球从左侧（电脑侧）边线出界 → 玩家得分 +1；从右侧（玩家侧）出界 → 电脑得分、数字 −1。允许负数，无限对局无终局。
- **开局**：静默等待 2 秒（无任何提示），球静止于中央，随后以随机方向获得恒定速度；此后速度大小不变，只改变方向。

## 验收标准

- [ ] F5 进入即 50% 灰场 + 中缝 + 两拍 + 中央球，2 秒后球随机启动。
- [ ] 球速恒定（球体 85% 不透明度）；撞上下墙反弹；撞拍带弧面角变化。
- [ ] W/S 与 ↑/↓ 都能控制红拍；球穿左侧出界计分 +1，右侧出界 −1，可显示负数。
- [ ] 电脑拍操作冻结约 0.1s（cfg 可调）；配置文件关冷却后电脑近乎实时。
- [ ] 中央巨大半透明计分数字随窗口缩放，观感两倍于早期版本。
- [ ] 无素材导入报错；Esc 可返回 hub。
- [ ] 图形与碰撞精确对齐（双树同步无错位）。

## 范围与非目标

- 不做：音效、粒子、难度分级、AI 学习、多球。只做一块干净的基础乒乓。
- 所有手感数值走配置文件，代码零魔法调参。
