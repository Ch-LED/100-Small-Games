# 06-simon — 策划案

## 定位

经典 Simon（西蒙记忆游戏）：四色扇形按随机顺序依次亮起并发出音调，玩家照着顺序复述一遍。每过一关序列加长一步、播放速度略微加快。**错一次即结束**（原作契约）。不做玩法创新。图形全部矢量绘制（`Polygon2D`），音效全部程序化合成——**无需任何外部素材**。

## 视觉与配色（全部矢量绘制，无外部素材）

- 场地：深色背景，正中是一块**圆盘**，由四个**环形扇区**拼成（中间留一个暗色圆芯），扇区之间留细缝。
- 四个扇区按方位对应四个方向键：
  - **上 = 绿**，**右 = 红**，**下 = 黄**，**左 = 蓝**。
- **未激活时是压暗的色块（约 62%），亮起时是原色**——对比强、色相也保得住。反过来把"亮起"往白里提是不行的：红色会变成粉色，看着像褪色而不是点亮。
- 中央圆芯：一块深色圆盘，压住四个扇区的内边。

## 音效（程序化合成，无外部素材）

启动时用代码合成 PCM 到 `AudioStreamWAV`，播放走 `AudioStreamPlayer` 池：

- **四个音调**：与四个扇区一一对应，取 **C 大调四音 `C4 / E4 / G4 / C5`**（互相区分度高、听感悦耳；**不声称复刻原作的具体音高**）。播放序列与玩家按键都响同一个音。
- **错误**：低沉的下行噪声爆响。
- **开局**：一声柔和起音。

## 核心体验

- **操作**（三种都可用，互为等价）：
  - 方向键：↑ / → / ↓ / ← 对应四个扇区。
  - WASD：`W` / `D` / `S` / `A` 同上。
  - 鼠标：**直接点扇区**（按点击位置相对圆心的角度判定，最贴近原作的触感）。
- **回合流程**：
  1. `ROUND n` 提示 → 序列**逐个亮起**（每个亮起 `step` 的约 6 成时间，其余为间隔）。
  2. 轮到玩家：依次按出刚才的序列。按对一个就亮一下、响一声。
  3. **全部按对** → 回合一过，序列**追加一步**，回到第 1 步重播。
  4. **按错** → 错误音 + 结算画面。
- **难度**：`step`（每步播放时长）随回合数递减，到下限封顶——序列越长、放得越快。
- **计分**：分数 = **通过的回合数**（即成功复述过的最长序列长度 − 1）；最高分在本次运行内累积。
- **界面**：顶部显示 `ROUND` 与 `BEST`；中央覆盖文字显示 `ROUND n` / `GAME OVER`。

## 作弊键与调试键

- **`[`（`cheat_toggle`）PEEK**：开启后在底部把**当前序列画成一排彩色圆点**，直接看到答案。记忆游戏最自然的作弊方式，也方便自测。
- **`P`（`debug_toggle`）**：只读状态读数（角落一行）——当前**阶段**、**第几步 / 共几步**、回合数、当前每步播放时长（毫秒）。**不显示序列内容**，是纯诊断。

## 验收标准

- [ ] 从 hub 进入即见四色圆盘，按空格开始。
- [ ] 序列会逐个亮起并发声；亮起的是对应的那块扇区、颜色明显提亮。
- [ ] 方向键 / WASD / 鼠标点击三种方式都能复述，按对时有亮起 + 音调反馈。
- [ ] 按对整段序列 → 回合 +1、序列加长一步、播放变快（到下限封顶）。
- [ ] 按错 → 错误音 + 结算画面，显示本局回合数与最高分；空格重开。
- [ ] `P` 显示阶段/步数/时长读数，且**关掉后立即消失**；`[` 显示序列圆点，关掉后消失。
- [ ] `Esc` 返回 hub。
- [ ] 无素材导入报错；所有调参走 `simon.cfg`，代码零魔法数。

## 范围与非目标

- 不做：生命/容错次数（**错一次即结束**是原作的契约）、双人对战、自定义音色、音量设置菜单、最高分持久化。
- 不做**序列回放**（原作失败时会把正确序列再放一遍）——留作后续可选项。
- 不引入任何外部美术/音频素材。
