# 17-bejeweled — 策划案

## 定位

经典三消：8×8 的棋盘上散着六种宝石，**交换相邻两颗**，只要换来横向或纵向**三个或更多同色连线**就消掉；消掉后上面的落下、新的从顶上补进来，**新落下的又凑成线就是连锁**，每多一层连锁分数翻倍。

**限时 90 秒**，比谁分高。时间到了就结算。

**开局一定不静默、也一定不卡死**：发牌时**不让任何一条线一开始就成立**，而且发完必须**至少有一个可行的交换**——一张没有走法的棋盘不是谜题，是让人干等。消完之后如果棋盘也没走法了，会自动重发。

图形全部由 `Control._draw()` 绘制，**无外部素材**；音效全部程序化合成。

## 视觉与配色（全部代码生成，无外部素材）

- **棋盘是深浅交错的格子**，一眼数得清行列。
- **六种宝石 = 六种颜色 + 六种轮廓**（圆 / 方 / 菱形 / 三角 / 六边形 / 星形）。**颜色不是唯一线索**——形状也各不相同，色觉不同的玩家照样能玩。
- 选中的格子有粗框，鼠标所在格有细框，`[` 提示的两格是青色框。
- 交换是**两颗宝石对滑**；消除是**缩小淡出**；下落是**从上方入场**。全部是补间动画，**不改任何数据**。

## 音效（程序化合成，无外部素材）

交换（短音）、交换被退回（低音）、消除（音高**随连锁层数上升**）、时间到（下行滑音）、破纪录（上行三音）。

## 核心体验

- **鼠标**：点一颗，再点相邻的一颗，交换。**点不相邻的格子会改选**，不会报错。
- **键盘**：方向键移动光标、空格选中/交换。
- **只有能凑成线的交换才会生效**。凑不成的会被**退回**，并响一声低音——**让玩家知道这一下被看见了、被拒绝了，而不是没按到**。
- **连锁**：一次消除后落下的宝石如果又凑成线，继续消，**每深一层，这一层的每颗宝石分值翻倍**。
- **特效宝石**：一次消掉 **4 连**，会在那一段的正中间留下一颗**炸弹**（下次被消掉时炸掉 3×3）；消掉 **5 连或更长**，留下的是**闪电**（炸掉整行整列）。
  - 特效宝石**颜色就是它诞生的那一段的颜色**，所以它仍然参与三消。它只是一颗"带标记的普通宝石"。
  - **炸到的特效会继续引爆**：炸弹炸到闪电，闪电再炸一行一列。展开是连锁的，不只看第一层。
  - 视觉：炸弹是**白色圆环 + 十字**，闪电是**白色菱形**，都压在宝石本身上——六种底色下都得看得清，所以用白色。
- **无走法自动重发**：棋盘上没有可行交换时，整盘重新发。
- **计分**：每颗宝石 10 分 × 当前连锁层数。

## 界面

四屏，整屏替换（与 10–16 同构）：

- **主菜单**：标题 + 最高分 + `PLAY 90 SECONDS` + `BACK TO HUB`。
- **对局**：顶栏 `SCORE / TIME / BEST`（最后 10 秒时间变红）；中央棋盘；底部只有一行 `ESC MENU`。
- **暂停**（`Esc`）：`RESUME` / `NEW ROUND` / `QUIT TO MENU`。暂停时**计时停住**。
- **结算**：`TIME` + 分数 + 最高分（破纪录时绿色 `NEW BEST`）；空格再来一局。

## 作弊键与调试键

**不在屏幕上写任何按键提示**——作弊是留给人自己发现的（DECISION_LOG 100）。

- **`P`（`debug_toggle`）**：只读叠加层——分数与剩余时间、选中的格、光标坐标、**当前已经成立的匹配数**、**是否还有可行走法**、提示与作弊开关、宝石种类与棋盘尺寸、最高分。**它只是读数，一格都不改。**
- **`[`（`cheat_toggle`）**：**把当前棋盘上任意一个可行的交换用青框标出来**。不是替你换，只是指出来——剩下那一下还得你自己点。
- **`]`（`super_cheat_toggle`）**：**允许交换不相邻的两颗宝石**，而且**换出来凑不成三连也照样保留**——这一下是在整理棋盘，不是在得分。拆掉的是三消最根本的一条约束："只能动相邻的"。选中的宝石会变成绿色 `#00E676`。

## 验收标准

- [ ] 从 hub 进入即见主菜单，显示最高分；`Esc` 回 hub。
- [ ] 开局棋盘**没有任何现成的三连**，且**一定有至少一个可行交换**（连开多局都成立）。
- [ ] 点两颗相邻宝石能交换；换出三连即消除，换不出会被退回并响低音。
- [ ] 消除后上方落下、顶部补充；**新宝石再凑成线会继续消**，连锁层数递增、分数按层翻倍。
- [ ] **下落动画走完真实距离**：掉三格就从三格高处滑下来，不是从头顶一格冒出来。
- [ ] **4 连留下一颗炸弹、5 连及以上留下一颗闪电**；它们被消除时分别炸掉 3×3 与整行整列，**炸到的特效继续引爆**。
- [ ] **棋盘没有可行交换时自动重发**。
- [ ] 90 秒倒计时，最后 10 秒时间变红；时间到进结算。
- [ ] `[` 用青框标出一个可行交换，再按一次更新/消失；**开局复位**。
- [ ] `]` 后能交换不相邻的两颗宝石，**且换不出三连也不退回**，选中的宝石变绿；再按还原；**开局复位**。
- [ ] 按 `P` 显示读数、再按消失，且**读数一格都不改**。
- [ ] 键盘能玩：方向键移光标、空格选中/交换。
- [ ] `Esc` 打开暂停菜单且**计时停住**；三条路都对。
- [ ] 存档不存在 / 损坏 / 版本不符都能启动，菜单上明说 `SAVE UNREADABLE`。
- [ ] 无素材导入报错；所有调参走 `bejeweled.cfg`，代码零魔法数。

## 范围与非目标

- 不做：特殊宝石（炸弹 / 闪电 / 换色）。
- 不做：步数模式、无尽模式、多关卡。
- 不做：触屏滑动（鼠标点击 + 键盘）。
- 不引入任何外部美术/音频素材。
