### 3.1 动画在视图里，判定在棋盘里

`BejeweledView` 负责三件事的**样子**：交换（两颗宝石对滑）、消除（缩小淡出）、下落（从上方入场）。它用两个惰性字典 `_offsets`（像素偏移）与 `_fades`（透明度）承载动画，**这两个字典不参与任何判定**。

`BejeweledPlay` 负责**发生了什么**，并且用**协程**串起来：

```
换 → 等动画 → 判定 → 没成：换回 + 等动画
                    → 成了：消除 → 等 → 落 → 等 → 再判 → …
```

`_busy` 挡住第二次点击。**"一次只做一件事"是从代码形状里长出来的，不是靠状态机枚举出来的。**

## 4. 数据模型（`bejeweled_board.gd`，`class_name BejeweledBoard`）

**纯逻辑，`extends RefCounted`**。

- `cells`：每格一个宝石种类（`-1` = 空）。
- **`deal()` 的三条保证**：填满、**不形成任何现成三连**、**至少有一个可行交换**。
  - 逐格发牌时，`_safe_kind()` 只排除"左边两格同色"和"上面两格同色"——这是到达该格时**唯一可能构成三连的两个方向**。右下方向还没填，构不成。
  - 发完 `has_move()` 为假就整盘重来（最多 20 次）。
- **`matched_cells()`**：横向、纵向各扫一遍连续段，长度 ≥ 3 的标记；**交叉格只报一次**（一个 L 形报 5 格，不是 6 格）。
- **`swap_makes_match()`**：换一下、看有没有匹配、**再换回来**——它不改变棋盘，只回答"这一下值不值"。
- **`apply_gravity()`**：每列从底往上压紧，顶部补新宝石。它**不回避三连**——落下来的宝石凑成线正是连锁，是玩法的一部分。
- **`has_move()` / `find_move()`**：遍历每个格子与它右边、下边的邻居，用 `swap_makes_match()` 判断。前者回答有没有，后者给出第一对。
- **`are_adjacent()`** 只管"是不是上下左右相邻"；**相邻是玩家规则，不是棋盘规则**——`]` 作弊正是取消这一条。
- **`last_moves` / `last_spawns`**：一次下落里每颗宝石从哪来、哪些格是新补的。**视图靠它把每颗宝石滑过真实距离**——只从上方一格入场会让"掉三格"看起来像凭空出现。

### 4.5 特效宝石

- `special`：每格一个枚举（`NONE` / `BOMB` / `LIGHTNING`）。**它就是一颗普通宝石加一个标记**，颜色照旧，照旧参与三消。
- **`matched_runs()`** 返回每一段的格子与方向；`pending_rewards()` 按**长度与方向**决定留什么：
  - **≥ 5 且水平 → 闪电**；**≥ 5 且竖直 → 超立方体**；**≥ 4 → 炸弹**。
  - 种在段的**正中**；一格被两段共用只出一颗。**方向在五连时才有意义**——这正是"五连要看方向"这条规则落进代码的地方。
- **`expand_specials()`** 把一次消除长大：炸弹带 3×3、闪电带整行整列，**被波及的特效继续引爆**（队列处理，`processed` 去重）。
- 特效跟着宝石一起下落（`apply_gravity` 同步移动 `special`），新补的宝石 `special` 恒为 `NONE`，被消除时归零。

## 5. 对局（`bejeweled_play.gd`）

- **计时 90 秒**，暂停时 `_process` 停住（`process_mode` 是默认的 `INHERIT`）。
- **交换失败会响一声低音**：让玩家知道这一下被看见了、被拒绝了，而不是没按到。
- **连锁计分**：第 n 层每颗宝石 `per_gem × n`，**按展开后的格数算**——炸得多就该得得多。
- **一次消除的顺序**：先算这一轮该留什么特效（`pending_rewards`，按原棋盘的位置），再展开特效算清空集合，然后播放、清除、种下特效、下落。**特效在清除之后、下落之前种下**，所以它会跟着下落，而不是凭空定在原地。
- **无走法自动重发**：一次连锁结算完，如果 `has_move()` 为假就整盘 `deal()`。**没有提示动画**——直接换一张盘，比弹一个"没有可用的走法"对话框更不打断节奏。
- **结束**：时间到 → `_over` → 延迟 0.9 秒发 `finished(score)`。

### 5.1 超立方体

- **单体**：交换后**消除场上所有与对面那颗宝石同色的宝石**（连同超立方体本身），再进连锁。
- **两个一起**：交换后**按行从上到下依次引爆全场所有特效**（每个 `CHARGE_STAGGER = 0.12` 秒闪一下）→ **整盘落定** → **全部消除**。两个超立方体本身也在这一下里消失。
- 两种交换**都不要求产生三连**——它们本身就是交换型特效。

### 5.2 冻结 0.8 秒

- **炸弹 / 闪电触发时**，视图先播 `animate_blast()`：白环从每颗被波及的格子扩散、淡出，**`CHARGE_TIME = 0.8` 秒**。
- **这段时间里对局协程停在 `await` 上**：不清除、不下落、玩家输入被 `_busy` 挡住。**"冻结物理"不是另加一个开关，是协程本来就串行。**
- **普通三连仍然用 0.16 秒**（`animate_clear`）——只有特效才值得停下来看。

## 6. 配置 `bejeweled.cfg`

| 分区 | 关键项 | 职责 |
| --- | --- | --- |
| `[board]` | `rows` `cols` `kinds` `gem_colors`（每种一颗颜色）`cell_size` 与配色、`gem_inset` | 棋盘与宝石外观 |
| `[round]` | `seconds` | 一局多长 |
| `[score]` | `per_gem` 与三个动画时长 | 计分与节奏 |
| `[audio]` | 各事件音高 | 听感 |
| `[hud]` | 字号与边距 | HUD |

- ⚠️ `BejeweledSettings` 每个键都有兜底值，加键时两处一起改。
- **宝石的形状按种类下标取**（`kind % 6`），不额外配置——形状是"颜色之外的第二种线索"，不是可调的风格。

## 7. 只读叠加层

`P`：分数与剩余时间、选中格、光标坐标、**当前匹配数**、**是否还有可行走法**、提示与作弊开关、种类与尺寸、最高分。**一格都不改。**

## 8. 程序化音频

交换 / 退回 / 消除（**音高随连锁层数上升**）/ 时间到（下行滑音）/ 破纪录 / 开局。相位积分渲染。

## 10. 风险 / TODO

| 事项 | 优先级 | 说明 |
| --- | --- | --- |
| 只有限时一种模式 | 中 | 经典还有步数模式与无尽模式。当前只有 90 秒比分数。 |
| 没有特殊宝石 | 中 | 四连不出炸弹、五连不出换色。玩法因此更平，但规则也更干净。 |
| 重发没有过渡 | 低 | 无走法时整盘瞬间换掉。加一个下落动画会更好看，但也更慢。 |
| 连锁没有额外提示 | 低 | 只靠音高上爬与分数跳动。要不要在屏幕上标 `CHAIN x3`，要问。 |

## 11. 验收

### 可自动校验的（headless）

```bash
godot --headless --path . --import
godot --headless --path . --script res://17-bejeweled/scripts/bejeweled_check.gd
godot --headless --path . res://17-bejeweled/bejeweled.tscn --quit-after 120
```

- 断言套件（`bejeweled_check.gd`，**84 项**）：
  - **发牌**：填满、**开局无匹配**、**有可行交换**；连发 40 次，两条保证一次不落。
  - **匹配**：3 / 4 / 5 连、纵向、**交叉只算一次**、断开的连线不报、空格之间不匹配。
  - **交换**：`swap_makes_match` 判定正确且**不改变棋盘**；相邻判定（对角不算）；**不相邻的交换棋盘允许**（作弊要用）。
  - **下落**：宝石落到底、顶部补新、满盘不动；`clear` 只清指定的格。
  - **走法**：发出来的盘 `find_move()` 给的一对真的能得分、**真的相邻**；2×2 的盘一定没有走法；`has_move` 与 `find_move` 结论一致。
  - **特效**：4 连出炸弹、**水平** 5 连出闪电、**竖直** 5 连出超立方体、3 连什么都不出；炸弹带 9 格、闪电带 9 格（5×5 的一行一列）、**炸到的特效继续引爆**；特效跟着宝石下落、新宝石不带特效、被消除时归零。
  - **下落记录**：`last_moves` 与 `last_spawns` 记下每颗移动的宝石与每一格补位，移动的目标格确实有宝石。
  - **配置**：棋盘是偶数边长、种类够多、一局有长度、每种宝石有颜色、放得进场地。
- **冒烟（一次性脚本，已跑完删除）**：真实 `play.tscn` 驱动**一整个回合**——发牌干净、有走法、棋盘居中、点击选中/取消、**通过 `find_move()` 做一次交换并等协程跑完**、确实得分、棋盘落定后无残留匹配且仍有走法、`[` 指向的交换真的成立、`]` 允许远距离交换、时间耗尽结束回合。**15 项全过。**

### 已跑过的

- `--import`：零 error / warning。
- 断言 **84 项**、冒烟 **15 + 8 项**全过。
- 主场景 headless 加载无脚本错误。

### 只有人能定的

- 观感：六种形状的辨识度、棋盘深浅交错会不会太花、宝石的描边粗细、选中/提示框够不够显眼。
- 手感：**交换与退回的动画速度**（`swap_time 0.12` / `clear_time 0.16` / `fall_time 0.16`）——快了看不清、慢了打断节奏。
- 听感：消除音随连锁上爬、退回那声低音。
- 难度：90 秒够不够、6 种宝石合不合适（更少更容易凑、更多更难读）。
