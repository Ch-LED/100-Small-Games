# 10-marble-race — 策划案

## 定位

**三维第三人称滚球竞速**。球在一条悬空的赛道上从起点滚到终点，玩家**不直接推动球**，而是控制球的**自转方向**，由自转与路面的**摩擦**把它带出去。鼠标控制视角，键盘控制自转；**不允许主动跳跃**。

这是全库**第一款 3D 游戏**，也是第一款带**关卡计时**与**跨会话存档**的游戏。

三条与传统小游戏不同的口径：

- **摩擦规律不必严格遵从现实物理**——球是"街机手感"的载体，不是仿真对象。凡是"更跟手、更好玩"与"更真实"冲突的地方，一律选前者。
- **赛道由曲线数据程序化生成**，不是手工摆块。道路的形状、宽窄、倾斜、有无护栏都记在数据里。
- **球与赛道都没有外部素材**：球是内置球体 + 代码生成的纹样，赛道是代码扫掠出的网格，天空用程序化材质。

## 视觉与配色

- **轻微像素化 + CRT**：3D 世界渲染在一张 640×360 的低分辨率画布上，再以最近邻放大铺满屏幕，叠一层轻量 CRT（扫描线 + 桶形畸变 + 暗角）。**三件套都要克制**——目标是"老监视器上玩 3D 游戏"的味道，不是把画面糊掉。
- **HUD 不参与像素化**，浮在 CRT 之上保持清晰——计时器是这款的命脉，每个数字都要一眼读得出来。
- **球必须带高对比纹样**（棋盘格或一道粗条纹）。纯色球转与不转在画面上完全一样，而"自转"正是这款唯一的输入；低分辨率下球只有十几像素，纹样是玩家唯一能读出自己动作的窗口。
- 赛道与天空的配色让**路面与空中的对比足够大**：玩家要在高速下判断"哪里还有路"，路面掉进背景里是致命的。
- 起点 / 终点 / 护栏用**三种一眼可辨的颜色**区分，不靠形状细节。

## 音效（程序化合成，无外部素材）

- **滚动声**：持续噪声层，**音量与音高随速度**——这是玩家判断快慢的主要听觉线索，比看计时器更即时。
- **碰墙 / 撞护栏**：短促噪声脉冲，**强度随撞击速度**。
- **掉落**：一声下行的长滑音。
- **过关**：上行小动机。
- **个人最佳**：比过关再高一层的一段音，和普通过关区分得开。

## 核心体验

- **操作**：
  - **键盘**（WASD / 方向键）：给出一个**相机相对**的自转方向——按"上/前"球朝屏幕里的远方加速，按"左"球朝屏幕左转。按住不松才持续给力，松开就靠惯性滚。
  - **鼠标**：控制第三人称视角的偏航与俯仰。俯仰有限位，不允许翻过头顶。
  - **不允许跳跃**——没有跳跃键，也没有任何腾空控制。
  - **空格**：暂停菜单里的确认 / 关卡开始前的出发。
- **运动模型（玩家的心智模型，不必等于真实物理）**：你给球的是一份**自转**，不是一份推力。所以：
  - 球在**光滑平直**的路面上加速慢、极速高；
  - 球在**上坡**会被自然拖慢，**下坡**会自己加速——坡是这款的节奏来源；
  - 球**撞墙会弹开**并损失速度；
  - 松开按键后球**会慢慢停下**（不是永动）。
- **失败**：球从赛道边缘掉下去 → 短暂停顿后**重开本关**（计时清零重来）。没有生命数、没有惩罚，只有时间。
- **目标**：用最短时间从起点到终点。

## 界面

- **主菜单**（本作的主场景，从 hub 进入后先看到它）：标题、`START`、`QUIT`。
- **选关界面**：列出所有赛道，每条显示**名称**与**最佳时间**（没跑过显示 `--:--.--`）。首版只有一条。
- **关卡内 HUD**：顶部**计时器**（本关当前用时，毫秒级）、进度指示（从起点到终点走了多少）、以及最佳时间的对照。
- **暂停菜单**（`Esc`）：`RESUME` / `RESTART` / `LEVEL SELECT`。
- **结算**：到终点后显示本关用时，并**与最佳时间对照**——破纪录时明确打出 `NEW RECORD`。

## 键位

三个全局键按项目约定接上：

- **`P`（`debug_toggle`）只读叠加**：画出**赛道中心线**（曲线的折线）、**球的速度矢量**、**当前接触面的法线**、以及**本关进度百分比**。纯诊断，不改变任何玩法。
- **`[`（`cheat_toggle`）**：**提高抓地力**——球更黏路面、转向更快、更不容易被弹飞。让这一局变简单。
- **`]`（`super_cheat_toggle`）**：**球自己跑完全程**。球被接管，沿赛道中心线一路滚到终点。绿色 `#00E676` 画在**赛道中心线**上，标出它正沿着什么走。
- 三者**彼此独立**；`[` 与 `]` **在每次开新关 / 重开本关时复位**（与既有的作弊复位习惯一致）。

## 验收标准

- [ ] 从 hub 进入后看到**主菜单**；`START` 进选关，`Esc` 回 hub，`QUIT` 退出程序。
- [ ] 选关界面列出赛道与最佳时间；首版一条；没跑过显示占位符。
- [ ] 进关后球停在起点，倒计时/出发提示后开始计时。
- [ ] 键盘能改变球的**自转方向**（相机相对），球因此**动起来**；鼠标能转视角，俯仰有限位。
- [ ] **没有跳跃**：任何按键都不能让球腾空。
- [ ] 上坡明显变慢、下坡明显加速（坡真的有作用）。
- [ ] 球撞墙会弹开并损失速度；**高速下不穿墙、不穿路面**。
- [ ] 松开按键后球会**停下**（不是永动）。
- [ ] 球掉出赛道 → 短暂停顿 → **本关重开**，计时清零。
- [ ] 到终点 → 结算显示用时，与最佳时间对照；破纪录时打出 `NEW RECORD`。
- [ ] **最佳时间写入存档**：退出游戏再进，选关界面上还在。
- [ ] 存档文件**不存在 / 损坏 / 版本不符**时，游戏照常启动（回退到空存档），不崩、不报错中断。
- [ ] `Esc` 分层正确：主菜单→hub、选关→主菜单、关卡中→暂停菜单（继续/重开/回选关）。
- [ ] 按 `P` 出现只读叠加（中心线 / 速度矢量 / 接触法线）；再按一次**立即消失**。
- [ ] 按 `[` 后球明显更稳更跟手；开新关自动复位。
- [ ] 按 `]` 后**什么都不做**，球自己沿中心线跑到终点；开新关自动复位。
- [ ] 画面有轻微像素化与 CRT 观感，且**计时器读数清晰**。
- [ ] 无素材导入报错；所有调参走 `marble-race.cfg`，代码零魔法数。

## 范围与非目标

- **不做跳跃**（刻意的，见"核心体验"）。
- 不做：多球、对手 AI、道具 / 加速带 / 氮气、漂移机制、赛道内分支路线。
- 不做赛道编辑器：赛道在 Godot 编辑器里拖控制点（见技术规格书 §5.3）。
- 首版**只做一条赛道**——先把"生成 → 跑 → 计时 → 过关 → 回选关"这条链路跑通，再添赛道。
- 不引入任何外部美术 / 音频素材。
