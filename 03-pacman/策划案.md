# 03-pacman — 策划案

## 定位

经典 Pac-Man 复刻：吃豆人在迷宫里吃光所有豆子，躲避四只幽灵；吃到能量豆后可以反过来吃幽灵。不做玩法创新，只把经典手感做扎实。

## 玩法

- **迷宫**：28×31 格，左右各有一条隧道（穿越到对面）。
- **吃豆人**：四个方向移动，吃到豆子加分；**吃掉全部豆子即过关**。
  - 小豆 10 分，能量豆 50 分。
- **能量豆**：找到后幽灵变蓝并可被吃，持续数秒；连吃多只按 **200 / 400 / 800 / 1600** 递增。
- **幽灵**：四只，各有不同追踪策略（见技术规格书 §6）。被幽灵碰到损失一条命。
- **水果**：每关在固定分数阈值（70 / 170 颗豆）时在幽灵屋上方出现，限时停留，吃到加分。
- **关卡**：吃过关后进入下一关，幽灵变快、能量豆持续时间变短；同一关卡循环若干轮后难度封顶。
- **生命**：初始 3 条，吃到 10000 分奖励 1 条。

## 视觉风格

- 深色背景 + 蓝色双线迷宫墙（经典配色），保留原作辨识度。
- 吃豆人黄色、四只幽灵红/粉/青/橙。
- 一切整数倍放大、NEAREST 过滤，保持像素硬边。

## 界面

- 顶部左右显示分数与最高分，中间下方显示剩余生命（吃豆人图标）。
- 关卡水果展示区在幽灵屋上方。

## 作弊键与调试键

- **`P`（`debug_toggle`）**：只读叠加，可视化幽灵寻路。
- **`[`（`cheat_toggle`）**：**穿墙**。吃豆人不再被墙挡住，整张迷宫拉直线可达。**只给他地图，不给安全**——墙照样画着，幽灵照样能吃他。
- **`]`（`super_cheat_toggle`）**：**幽灵掉头逃跑**。开启后幽灵的目标格从"追吃豆人"变成**吃豆人在它自己身上的镜像**（`2 × 自己的格 − 吃豆人的格`）——瞄准一个人的倒影，就是在远离他；路口规则、不回头、幽灵屋纪律**全部沿用原样**，只有"瞄准哪一格"被换掉，所以四只幽灵的个性还在。
  - **四只幽灵全部变绿**即说明开着（能量豆的蓝色不受影响，那是另一个状态）。
  - **每局重开时自动关**（与其它游戏一致：作弊按"局"复位，不按关）。

## 验收标准

- [ ] 迷宫与豆子布局正确，豆子吃干净即过关。
- [ ] 四方向移动与转向预输入（提前按方向，到路口自动转向）手感正常。
- [ ] 隧道左右穿越不卡顿。
- [ ] 能量豆生效时四只幽灵同时变蓝并可被吃，连吃分数递增。
- [ ] 四只幽灵行为有明显差异，不会叠在一起走。
- [ ] 吃 70 / 170 颗豆时水果出现，限时消失。
- [ ] 被幽灵碰到扣一条命，生命耗尽进结算；吃豆人播放死亡动画。
- [ ] 过关后难度提升（幽灵变快、能量豆变短）。
- [ ] 按 `[`（`cheat_toggle`）后**吃豆人可以直接穿墙走**（墙照画、幽灵照吃人）；重开一局自动关。
- [ ] 按 `]`（`super_cheat_toggle`）后**四只幽灵变绿并掉头远离吃豆人**（追得越紧退得越快），迷宫可以慢慢吃完；再按一次恢复成原来那套追击；**重开一局自动关**。
- [ ] `Esc` 返回 hub，有程序化音频。

## 范围与非目标

- 不做：原版的"幽灵 AI bug"还原、关卡间过场动画、双人模式、连击彩蛋。
- 所有调参走 `pacman.cfg`，代码零魔法数。
