# 16-sokoban — 技术规格书

> 依据：`16-sokoban/策划案.md`。四屏切换沿用 10–15 的形状。与实现冲突时修正实现。

## 1. 运行与返回

- 编号 16，slug **`sokoban`**，目录 `16-sokoban`，主场景 `sokoban.tscn`。
- 只从 hub 桌面进入；`Esc` 在菜单里回 hub、在对局里开暂停菜单。
- 逻辑分辨率 **1280×720**。

### 3.1 棋盘没有逐格节点

墙、地板、目标、箱子、玩家全部在**一次 `_draw`** 里画完。箱子和玩家单独走第二遍，保证它们永远压在地板与目标圈之上。

## 4. 数据模型（`sokoban_level.gd`，`class_name SokobanLevel`）

**纯逻辑，`extends RefCounted`**。

- 三份逐格字节数组：`walls`、`goals`、`boxes`；玩家是一个格号。
- **棋盘外一律算墙**（`is_wall` 对越界返回 true）——关卡不要求是矩形，参差的边缘正好挡住"把箱子推出地图"。
- `start_boxes` / `start_player` 保存开局，`restart()` 据此复位。
- **解析时校验**：没有玩家、没有箱子、或箱子数与目标数不等 → 返回 false。**一个摆错的文件应该在加载时报错**，而不是让人玩到一半才发现过不了。

### 4.1 移动

`move(direction)` 返回 0（没动）/ 1（走）/ 2（推）：

- 目标格是墙 → 0。
- 目标格有箱子 → 看**箱子后面那格**：墙或箱子 → 0；否则箱子与玩家一起前进，返回 2。
- 否则玩家前进，返回 1。

### 4.2 撤销

每一步（走或推）前推一份快照：`boxes` 的拷贝 + 玩家 + 步数 + 推数。**可以一路退回开局**。

### 4.3 死角

`stuck_boxes()` 数出"上下有一面墙 **且** 左右有一面墙"、且不在目标点上的箱子——它们再也动不了了。**只给 `P` 读数用**，不参与任何判定。

### 4.4 两个作弊

- **`[` 拉**：`pull(direction)` —— 玩家朝 `direction` 走，**身后**（`-direction`）是箱子就把它拖过来。按住 `X` + 方向触发。
- **`]` 穿箱**：`move_ghost(direction)` —— 玩家走进箱子所在的格子，**箱子不动**；**墙仍然挡**。拆掉的是"箱子挡路"，不是关卡的形状。

## 5. 对局（`sokoban_play.gd`）

- **过关**：每次成功移动后判 `is_won()`（所有目标点都有箱子）。**延迟 0.65 秒**再发 `finished(moves, pushes)`。
- **音效**：推箱子与走路分开；箱子归位时额外一声高音（比较移动前后的 `boxes_on_goals()`）。
- **重开本关**：`Backspace`，或暂停菜单里的 `RESTART LEVEL`——**重开本关而不是回到第一关**。

## 6. 配置 `sokoban.cfg`

| 分区 | 关键项 | 职责 |
| --- | --- | --- |
| `[board]` | 底 / 墙 / 墙边 / 地板 / 目标 / 箱子 / 箱子边 / 归位箱子 / 归位边 / 玩家 / 玩家边 / 作弊绿 / 三种文本色、`cell_size`、`corner_scale` | 棋盘外观 |
| `[audio]` | 五个基频 + 两组音阶 | 音高 |
| `[hud]` | `font_size` `margin` | HUD |

`cell_size = 56`：最大关卡 10 列 × 56 = 560，在 1280 宽里从容。

## 7. 只读叠加层

`P`：关卡与尺寸、步数、推数、撤销可用性、箱子数与归位数、**死角箱子数**、玩家坐标、两个作弊开关、本关最佳。**一步都不走。**

## 8. 程序化音频

走 / 推 / 撞墙 / 撤销 / 归位 / 过关 / 破纪录 / 开局。相位积分渲染（f 变化时不跳音）。

## 9. 输入

**本作没有往 `project.godot` 加新键**——复用 `arrow_*` / `wasd_*` / `key_z` / `erase`。

| 语义 | 来自 |
| --- | --- |
| `sokoban_up/down/left/right` | `arrow_*` / `wasd_*` |
| `sokoban_undo` | `key_z` |
| `sokoban_restart` | `erase` |

**拉箱子用的是 `key_x` 按住**（`Input.is_action_pressed`），不是语义动作——它是个修饰键，不是一次按下。

## 10. 风险 / TODO

| 事项 | 优先级 | 说明 |
| --- | --- | --- |
| 只有七关 | 中 | 关卡是手写的，加关卡要同时过求解器。表在那儿，加就是往 `levels/` 放文件。 |
| 没有提示 / 自动求解 | 低 | 卡住只能重开或撤销。Sokoban 的传统。 |
| `cell_size` 固定 | 低 | 大关卡（>20 列）会超出场地。当前最大 10 列。 |
| 死角只看墙不看箱子 | 低 | 被别的箱子挤死的箱子不会被计入。`P` 里那个数是**提示**，不是判定。 |

## 11. 验收

### 可自动校验的（headless）

```bash
godot --headless --path . --import
godot --headless --path . --script res://16-sokoban/scripts/sokoban_check.gd
godot --headless --path . res://16-sokoban/sokoban.tscn --quit-after 120
```

- 断言套件（`sokoban_check.gd`，**57 项**）：
  - **解析**：墙 / 玩家 / 箱子 / 目标都能认出；`*` 与 `+` 两种"叠"的写法都算对；**没有玩家、没有箱子、箱数与目标数不等的一律拒收**；参差行可用。
  - **移动**：撞墙不动、走空地、推箱子、**箱子推不动箱子**、**推不进墙**、被拒后盘面不变；`is_won` 与归位计数。
  - **拉**：玩家离开、箱子跟到玩家刚才的格子、原位置空出来。
  - **撤销**：逐步回退、计数一并回退、退到开局、退空后拒绝。
  - **死角**：墙角箱计入、目标点上的箱不计。
  - **每一关都能通关**：把 `levels/*.txt` 全部喂给 BFS 求解器，**必须返回一个正数**，并打印最短步数。
- **冒烟（一次性脚本，已跑完删除）**：真实 `play.tscn` 驱动——关卡加载、棋盘居中、撞墙、推箱、撤销回退计数、`]` 穿箱且不推、拉箱子、推到目标过关。**18 项全过。**

### 已跑过的

- `--import`：零 error / warning。
- 断言 **57 项**、冒烟 **18 项**全过。
- 七关求解器结果：**2 / 1 / 4 / 6 / 9 / 8 / 13 步**（01–07），最慢的一关 181 ms。

### 只有人能定的

- 观感：墙的"砖感"、目标圈与箱子的区分度、归位变绿够不够醒目、`cell_size 56`。
- 手感：一步一格的移动节奏、撤销是否够快。
- 听感：推箱与走路的音高差、归位那一声。
- 难度：七关的曲线（尤其第 7 关是不是跳得太快）。
