# 16-sokoban — 策划案

## 定位

经典推箱子：把每一个箱子推到目标点上。箱子**只能推不能拉**，不能穿墙，也不能同时推两个；推错方向可能把它顶进死角，那一关就废了——所以撤销是必须的。

七个手写关卡，从"推两下就过"到"三个箱子各要找路"。

**关卡是手写文本文件**（`levels/NN.txt`），用的是 Sokoban 的标准字符表，改关卡不用碰代码。**每一关都过求解器验证**——"这关能过"是断言**检查**出来的，不是设计者**希望**出来的。

图形全部由 `Control._draw()` 绘制，**无外部素材**；音效全部程序化合成。

## 视觉与配色（全部代码生成，无外部素材）

- **墙是深蓝实心块**，左上有一道亮边——读起来像一段砖墙。
- **地板是更深的底色**，目标点是一个**空心的青圈**。
- **箱子是琥珀色方块**，推上目标后变成**绿色**——一眼看出还剩几个没归位。
- **玩家是橙色圆点**。

## 音效（程序化合成，无外部素材）

走一步（短音）、推箱子（低一点的短音）、撞墙走不动（更低的音）、撤销（中低音）、箱子归位（高音）、过关（上行四音）、破纪录（上行三音）。

## 核心体验

- **方向键 / WASD** 移动，一步一格；站到箱子旁边往箱子方向走就是推。
- **`Z` 撤销**（可以一路退回开局）、**`Backspace` 重开本关**。
- **过关**：所有目标点上都踩着箱子。
- **计分**：只记**步数**（推动也算一步），每关各记一个最少步数。

## 关卡

七个手写关卡，`levels/01.txt` … `07.txt`，按文件名排序。

格式是标准 Sokoban 字符表：

| 字符 | 含义 |
| --- | --- |
| `#` | 墙 |
| 空格 | 地板 |
| `$` | 箱子 |
| `.` | 目标点 |
| `*` | 箱子在目标点上 |
| `@` | 玩家 |
| `+` | 玩家在目标点上 |

**解析时会校验**：没有玩家、没有箱子、或者箱子数与目标数不相等，一律拒收——一个摆错的文件应该在加载时报错，而不是让人玩到一半发现过不了。

## 界面

四屏，整屏替换（与 10–15 同构）：

- **主菜单**：标题 + `CONTINUE LEVEL n` / `START FROM LEVEL 1` + 已通关数 + `BACK TO HUB`。
- **对局**：顶栏 `LEVEL n/总数 / MOVES / PUSHES / BOXES 已归位/总数`；中央棋盘；底部只有一行 `ESC MENU`。
- **暂停**（`Esc`）：`RESUME` / `RESTART LEVEL` / `QUIT TO MENU`。
- **结算**：`LEVEL n CLEARED` + 步数 + 最佳（破纪录时绿色 `NEW BEST`）；空格进下一关。

## 作弊键与调试键

**不在屏幕上写任何按键提示**——作弊是留给人自己发现的（DECISION_LOG 100）。

- **`P`（`debug_toggle`）**：只读叠加层——关卡与尺寸、步数、推数、是否有可撤销的操作、箱子与已归位数、**被顶进死角的箱子数**、玩家坐标、两个作弊开关、本关最佳。**它只是读数，一步都不走。**
- **`[`（`cheat_toggle`）**：**允许拉箱子**。按住 `X` 再按方向，玩家走开、身后的箱子跟过来。
  - 推箱子最真实的一个死法就是"把它顶进角落"，拉这一下正好救回来。
- **`]`（`super_cheat_toggle`）**：**玩家可以穿过箱子**（墙仍然挡）。拆掉的是"你必须绕路走到箱子后面"这条约束——有箱子堵住通道时直接穿过去。玩家在穿箱子时**变绿** `#00E676`。

## 验收标准

- [ ] 从 hub 进入即见主菜单，显示已通关进度；`Esc` 回 hub。
- [ ] `CONTINUE` 从上次进度开始，`START FROM LEVEL 1` 从头开始。
- [ ] 方向键 / WASD 能走；走到墙边会被挡住；站到箱子旁边能推动它。
- [ ] **箱子推不动第二个箱子**；**推不进墙**。
- [ ] 箱子推上目标点变绿；所有目标点都有箱子时过关。
- [ ] `Z` 撤销（可一路退回开局）；`Backspace` 重开本关。
- [ ] 按 `[` 后**按住 `X` + 方向**能把身后的箱子拉过来，再按还原；**开局复位为关**。
- [ ] 按 `]` 后玩家能**穿过箱子**（墙仍挡），玩家变绿；再按还原；**开局复位为关**。
- [ ] 按 `P` 显示读数（含**死角箱子数**）、再按消失，且**读数一步都不走**。
- [ ] 过关后进结算，步数进最佳；空格进下一关；最后一关后回菜单。
- [ ] `Esc` 打开暂停菜单；三条路都对。
- [ ] 存档不存在 / 损坏 / 版本不符都能启动，菜单上明说 `PROGRESS UNREADABLE`。
- [ ] **每一关都能被求解器打通**（断言强制）。
- [ ] 无素材导入报错；所有调参走 `sokoban.cfg`，代码零魔法数。

## 范围与非目标

- 不做：关卡编辑器、自定义关卡导入。
- 不做：时间限制、星级评价、提示/自动求解。
- 不做：鼠标操作（键盘游戏）。
- 不引入任何外部美术/音频素材。
